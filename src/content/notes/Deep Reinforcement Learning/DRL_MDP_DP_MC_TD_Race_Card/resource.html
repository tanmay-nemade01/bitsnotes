1. Concept Placement

These four methods form the backbone of the course. They are ordered by how much they assume about the environment model:

MDP — the framework
Lecture 1
Defines the agent–environment interface: states, actions, transitions, rewards, discount γ. Not an algorithm — the language every later method speaks. Introduction to Reinforcement Learning →
DP — plan with the model
Lectures 2, 6
Policy evaluation, policy iteration, value iteration. Requires the full transition model p(s′, r | s, a). Bootstraps from its own value estimates. Dynamic Programming for MDPs →
MC — learn from complete episodes
Lectures 7, 9
Model-free. Averages actual returns over sampled episodes. No bootstrapping — waits until the episode ends. Monte Carlo Methods →
TD — learn from single steps
Lectures 9, 10
Model-free and bootstrapping. Updates from one transition using the current estimate of the next state. The bridge between MC and DP. TD Learning: TD(0), SARSA, Q-Learning →

4. Common Mistakes

  • MC on continuing tasks. Monte Carlo needs a terminal state to compute a return — it cannot learn from non-terminating episodes without artificial cutoffs.
  • DP without a model. Value/Policy iteration are useless when p(s′, r | s, a) is unknown; that is exactly when you switch to MC or TD.
  • Confusing TD target with MC return. TD uses the estimated next value (bootstrapping); MC uses the actual sampled return.
  • Forgetting the discount. In continuing tasks γ < 1 is mandatory for a bounded return; in episodic tasks γ = 1 is allowed.

5. Worked Example — tiny gridworld

State A transitions to terminal B with reward +10. Current estimate V(A) = 0, γ = 1, α = 0.5.

DP (full backup)
V(A) ← R + γV(B) = 10 + 1·0 = 10. Uses the model directly.
MC (after episode)
Return G = 10. Average over visits → V(A) → 10. Requires the episode to finish first.
TD(0) (one step)
V(A) ← V(A) + α[R + γV(B) − V(A)] = 0 + 0.5[10 + 0 − 0] = 5. Bootstraps immediately, then converges with more steps.
Takeaway: all three converge to V(A) = 10, but DP needs the model, MC waits for the end, and TD learns after a single step by bootstrapping.
