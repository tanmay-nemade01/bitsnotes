9.1 The Role of Reinforcement Learning in Modern AI

Hook: Can you name a modern AI system that does not use some form of trial-and-error learning? From ChatGPT to self-driving cars, the answer is increasingly "none." Reinforcement Learning is the engine behind this shift — and it is no longer confined to niche control problems.

9.1.1 RL as the Foundation for Iterative Refinement

Intuition: Think of RL as the process of learning to cook. You try a recipe, taste the result, adjust the salt, try again. Each iteration makes you a better cook. RL does the same for AI: it takes an action, observes the outcome (reward), and adjusts its strategy to do better next time. The cycle — act, observe, improve — is what drives every RL system.
Formalize: Reinforcement Learning is a computational approach to learning from interaction. An agent takes actions in an environment, receives rewards (scalar feedback signals), and updates its policy (the mapping from situations to actions) to maximize cumulative reward over time.

Key terms:
  • Agent: the learner/decision-maker
  • Environment: everything the agent interacts with
  • State \(s\): the situation the agent is in
  • Action \(a\): what the agent can do
  • Reward \(R_t\): scalar feedback at time \(t\)
  • Return \(G_t\): cumulative (possibly discounted) sum of future rewards: \(G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \ldots\)
  • Policy \(\pi(a|s)\): probability of taking action \(a\) in state \(s\)

Reinforcement Learning has become the foundation for almost all modern AI tasks. A few years ago, RL use cases were limited to domains like thermal power plant control — using sensors to measure physical parameters and using RL to keep them in control. Today, RL applications are far more prevalent.

Consider an information retrieval pipeline: you submit a query, the system tries to understand the query, decomposes it, fetches relevant documents, and ranks them so the most relevant appears at the top. With LLMs and RAG (Retrieval-Augmented Generation), there is a need to iteratively refine results. Iterative refinement — keep improving performance — is where RL comes in.

Analogy — the student preparing for an exam: A student solves a practice paper (action), checks the answer key (reward), learns what went wrong (update), and solves the next paper better. The cycle of "attempt → feedback → improve" is RL in human form. The student does not need a mathematical model of the exam — they learn purely from experience. This is the essence of model-free RL.

Even LLM training pipelines now use RL. There are algorithms like DPO (Direct Preference Optimization), but without understanding the basics of RL, it is impossible to adapt such algorithms to specific requirements. Unlike classic algorithms like quicksort — which are done, tested, and simply called — modern RL algorithms are recent and often need to be adapted to particular scenarios. This is why foundations are critical.

Concrete example — LLM alignment with RLHF:
  1. A language model generates a response (action).
  2. A human rates the response as helpful or unhelpful (reward).
  3. A reward model is trained to predict human preferences.
  4. The LLM's policy is updated using RL (specifically PPO) to maximize the predicted reward.
  5. The cycle repeats, and the LLM becomes increasingly aligned with human preferences.
This is RL in production — and it depends on the same concepts (policy, reward, value, return) covered in this lecture.
Scope: The RL methods in this course apply to problems where:
  • The agent interacts with an environment sequentially
  • Feedback comes as scalar rewards (not full labels)
  • The goal is to maximize long-term cumulative reward
  • The environment may be unknown (model-free setting)
RL is not the right tool when you have a fixed labeled dataset and need one-shot predictions — that is supervised learning's domain.

Visual Intuition: Picture the RL loop as a circle: Agent → Action → Environment → Reward + New State → Agent (update) → ... This agent-environment interaction loop is the central diagram of RL. The agent sits on one side, the environment on the other. The only communication channels are actions (agent → environment) and observations + rewards (environment → agent). Every RL algorithm, from the simplest bandit to the most complex LLM trainer, fits this loop.

Recap: RL is learning what to do (policy) by trying things (actions) and seeing what works (rewards). It powers everything from game-playing AI to LLM alignment. Bridge: Before building optimal policies, we need to evaluate a given policy — which is exactly what Monte Carlo methods do.

9.3 Recap: On-Policy Monte Carlo Methods

9.3.1 What Are Monte Carlo Methods?

Hook: Imagine learning to play chess without ever being told the rules. You just play thousands of games, and after each game, you know whether you won or lost. Over time, you figure out which moves lead to wins. That is Monte Carlo RL — learning solely from the outcomes of complete experiences.
Definition: Monte Carlo (MC) methods are model-free RL techniques that learn value functions and optimal policies by averaging sample returns from complete episodes. They do not require a model of the environment's dynamics — only experience in the form of state-action-reward sequences.

9.3.2 Policy Evaluation with MC

Policy Evaluation (Prediction): Given a fixed policy \(\pi\), estimate the value function \(V^\pi(s)\) or action-value function \(Q^\pi(s,a)\) — the expected return starting from state \(s\) (and taking action \(a\)) and following \(\pi\) thereafter.

\[ V^\pi(s) = \mathbb{E}_\pi[G_t \mid S_t = s] \approx \frac{1}{N} \sum_{i=1}^{N} G_i(s) \]

9.3.3 Symbol Registry — On-Policy MC Control

9.3.4 On-Policy First-Visit MC Control Algorithm

Initialize π as an arbitrary ε-soft policy
Initialize Q(s,a) arbitrarily for all s, a
Initialize Returns(s,a) as empty list for all s, a

Repeat forever:
    Generate an episode S_0, A_0, R_1, S_1, A_1, R_2, ..., S_T using π
    G ← 0
    For t = T-1 down to 0:
        G ← γ * G + R_{t+1}
        Unless (S_t, A_t) appears in S_0, A_0, ..., S_{t-1}, A_{t-1}:
            Append G to Returns(S_t, A_t)
            Q(S_t, A_t) ← average(Returns(S_t, A_t))
            A* ← argmax_a Q(S_t, a)
            For all a in A(S_t):
                π(a|S_t) ← { 1 - ε + ε/|A|  if a = A*
                           { ε/|A|            otherwise
The fundamental tension of On-Policy MC: The policy \(\pi\) plays two roles simultaneously: generating experience (exploration) and being optimized (exploitation). A policy generating experience must explore (cannot always pick the greedy action), but the goal is to become optimal (mostly picking the greedy action). One policy is forced to serve two masters.

9.4 Motivation for Off-Policy Learning

9.4.1 The Two-Role Tension & Decoupling

Off-policy learning solves the exploration-exploitation tension by decoupling the agent into two separate policies:

Off-policy learning separates exploration from optimization using two different policies:

PolicyRoleDescription
Behavior policy \(b\)Teacher / ExplorerGenerates experience. Can bring prior knowledge, safety norms, constraints. Soft policy (\(b(a|s) > 0\)).
Target policy \(\pi\)Learner / OptimizerThe policy being evaluated or improved. Starts arbitrary, converges to greedy/optimal.
The professor's analogy (Dr. Kalam): The teachers who taught Dr. A.P.J. Abdul Kalam did not become president or rocket scientists. The learner went beyond. The teacher allowed the learner to explore, learn, and improve. The behavior policy is the teacher — it provides the raw material. The target policy is the student — it can surpass the teacher.

9.4.2 Coverage Assumption

The Coverage Assumption: For off-policy evaluation to make sense, the behavior policy \(b\) must give non-zero probability to every action that the target policy \(\pi\) may take: \[ \pi(a \mid s) > 0 \implies b(a \mid s) > 0 \quad \text{for all } s, a. \] If \(\pi(a|s) > 0\) but \(b(a|s) = 0\), then episodes generated by \(b\) will never take action \(a\) in state \(s\), making it impossible to gather data about \(\pi\)'s value at that state-action pair.

9.5 Foundations of Importance Sampling

9.5.1 General Expectation Transformation & Proof Idea

General Importance Sampling: Suppose we wish to estimate the expectation of a random variable \(X\) under a target distribution \(\Pr_\pi(X)\), but we only have samples drawn from a behavior distribution \(\Pr_b(X)\). Under the coverage assumption, we can transform the expectation as follows: \[ \mathbb{E}_\pi[X] = \sum_x x \cdot \Pr_\pi(x) = \sum_x x \cdot \frac{\Pr_\pi(x)}{\Pr_b(x)} \Pr_b(x) = \mathbb{E}_b \left[ \frac{\Pr_\pi(X)}{\Pr_b(X)} X \right] \] In Monte Carlo RL, the "sample" is a full trajectory \(\tau = (S_t, A_t, R_{t+1}, S_{t+1}, A_{t+1}, \ldots, S_T)\), and the random variable is the return \(G_t\). The expected return under the target policy \(\pi\) starting from state \(s\) is: \[ v_\pi(s) = \mathbb{E}_b \big[ \rho_{t:T-1} G_t \mid S_t = s \big] \] where \(\rho_{t:T-1}\) is the importance-sampling ratio for the trajectory segment.

9.5.2 Trajectory Probability and Model Dynamics Cancellation

Trajectory Probability under \(\pi\) vs. \(b\): Consider a trajectory segment starting at time \(t\) and ending at termination \(T\): \[ A_t, S_{t+1}, A_{t+1}, \ldots, S_T \] Under policy \(\pi\), the probability of observing this sequence conditioned on \(S_t\) is: \[ \Pr\{A_t, S_{t+1}, A_{t+1}, \ldots, S_T \mid S_t, A_{t:T-1} \sim \pi\} = \prod_{k=t}^{T-1} \pi(A_k \mid S_k) p(S_{k+1} \mid S_k, A_k) \] Under behavior policy \(b\), the probability is: \[ \Pr\{A_t, S_{t+1}, A_{t+1}, \ldots, S_T \mid S_t, A_{t:T-1} \sim b\} = \prod_{k=t}^{T-1} b(A_k \mid S_k) p(S_{k+1} \mid S_k, A_k) \] Taking the ratio of the two trajectory probabilities: \[ \rho_{t:T-1} = \frac{\prod_{k=t}^{T-1} \pi(A_k \mid S_k) p(S_{k+1} \mid S_k, A_k)}{\prod_{k=t}^{T-1} b(A_k \mid S_k) p(S_{k+1} \mid S_k, A_k)} = \prod_{k=t}^{T-1} \frac{\pi(A_k \mid S_k)}{b(A_k \mid S_k)} \] Model-Free Property: The environment transition probabilities \(p(S_{k+1} \mid S_k, A_k)\) cancel completely from numerator and denominator! Thus, computing \(\rho_{t:T-1}\) requires knowing only the policy probabilities \(\pi\) and \(b\), keeping off-policy MC entirely model-free.

9.5.4 Numerical Worked Example: Trajectory Probability & Ratio

Problem (Section 3.4 in Lecture Notes): Suppose a trajectory generated by behavior policy \(b\) follows three decisions: \[ (s_0, a_1, s_1, a_2, s_0, a_1, T) \] Let policy probabilities be: \[ \pi(a_1 \mid s_0) = 0.8, \quad b(a_1 \mid s_0) = 0.5 \] \[ \pi(a_2 \mid s_1) = 0.7, \quad b(a_2 \mid s_1) = 0.4 \] Step 1: Compute importance ratio \(\rho\): \[ \rho = \left(\frac{\pi(a_1 \mid s_0)}{b(a_1 \mid s_0)}\right) \cdot \left(\frac{\pi(a_2 \mid s_1)}{b(a_2 \mid s_1)}\right) \cdot \left(\frac{\pi(a_1 \mid s_0)}{b(a_1 \mid s_0)}\right) = \left(\frac{0.8}{0.5}\right) \times \left(\frac{0.7}{0.4}\right) \times \left(\frac{0.8}{0.5}\right) \] \[ \rho = 1.6 \times 1.75 \times 1.6 = \mathbf{4.48} \] Step 2: Compute Ordinary Importance-Weighted Return: If the observed return for this trajectory is \(G = 3\), then: \[ \text{Weighted Return } \rho G = 4.48 \times 3 = \mathbf{13.44} \] Interpretation: Because \(\rho = 4.48 > 1\), this trajectory is \(4.48\) times more likely under the target policy \(\pi\) than under behavior policy \(b\). The observed return of \(3\) is upweighted to \(13.44\) to reflect its higher frequency under \(\pi\).

9.6 Off-Policy Prediction: First-Visit vs. Every-Visit & Estimators

9.6.1 Visit Set Notation: \(\mathcal{T}_{FV}(s)\) vs. \(\mathcal{T}_{EV}(s)\)

To evaluate \(v_\pi(s)\) across multiple episodes, we collect the time steps at which state \(s\) is visited:

  • \(\mathcal{T}_{EV}(s)\): The set of all time steps in all episodes at which \(S_t = s\) (Every-Visit collection).
  • \(\mathcal{T}_{FV}(s)\): The set of only the first time step in each episode at which \(S_t = s\) (First-Visit collection).

For instance, if one episode visits states \(A, B, A, T\), then \(\mathcal{T}_{EV}(A)\) receives two time indices from that episode, whereas \(\mathcal{T}_{FV}(A)\) receives only the first index.

9.6.2 Ordinary vs. Weighted Importance-Sampling Estimators

Using a generic visit set \(\mathcal{T}(s)\), we define two primary estimators for state-value evaluation:

1. Ordinary Importance-Sampling Estimator (\(V^{OIS}(s)\)): \[ V^{OIS}(s) = \frac{\sum_{t \in \mathcal{T}(s)} \rho_{t:T(t)-1} G_t}{|\mathcal{T}(s)|} \] Simple arithmetic average of importance-weighted returns. Divided by total visit count \(|\mathcal{T}(s)|\).

2. Weighted Importance-Sampling Estimator (\(V^{WIS}(s)\)): \[ V^{WIS}(s) = \frac{\sum_{t \in \mathcal{T}(s)} \rho_{t:T(t)-1} G_t}{\sum_{t \in \mathcal{T}(s)} \rho_{t:T(t)-1}} \] Weighted average normalized by the sum of importance ratios.

9.6.3 Numerical Comparison: First-Visit vs. Every-Visit Returns

Example (Section 6.1 in Lecture Notes): Consider a single episode: \(S_0 = A, S_1 = B, S_2 = A, S_3 = T\). State \(A\) is visited twice.
Let observed returns be \(G_0 = 5\) and \(G_2 = 2\). Let suffix ratios be \(\rho_{0:2} = 3\) and \(\rho_{2:2} = 1.5\).

First-Visit Ordinary IS: Uses only the first visit (\(t=0\)): \[ V^{OIS}_{FV}(A) = \rho_{0:2} G_0 = 3 \times 5 = \mathbf{15} \] Every-Visit Ordinary IS: Uses both visits (\(t=0\) and \(t=2\)): \[ V^{OIS}_{EV}(A) = \frac{\rho_{0:2} G_0 + \rho_{2:2} G_2}{2} = \frac{3(5) + 1.5(2)}{2} = \frac{15 + 3}{2} = \mathbf{9} \] First-Visit Weighted IS: \[ V^{WIS}_{FV}(A) = \frac{3(5)}{3} = \mathbf{5} \] Every-Visit Weighted IS: \[ V^{WIS}_{EV}(A) = \frac{\rho_{0:2} G_0 + \rho_{2:2} G_2}{\rho_{0:2} + \rho_{2:2}} = \frac{15 + 3}{3 + 1.5} = \frac{18}{4.5} = \mathbf{4} \]

9.8 Bias, Variance, and Infinite Variance in Off-Policy Estimation

9.8.1 Empirical MSE Analysis: Reading the Blackjack Plot

In Sutton & Barto (Figure 5.4), state-value estimation in off-policy Blackjack is analyzed by plotting Mean-Squared Error (MSE) against the number of episodes (log scale):

  • Ordinary Importance Sampling (Green Curve): Unbiased for first-visit MC, but starts with high error and exhibits extreme variance spikes even after millions of episodes. A single high-ratio trajectory can drastically distort the estimate.
  • Weighted Importance Sampling (Red Curve): Biased in early finite samples due to random normalization, but error drops rapidly and smoothly. In practice, its variance is dramatically lower.

9.8.3 Formal Mathematical Proof of Infinite Variance

The One-State MDP Example (Sutton & Barto §5.5): Consider an MDP with a single non-terminal state \(s\) and two actions: \(\text{left}\) and \(\text{right}\).

  • Action \(\text{right}\) transitions to terminal state \(T\) with reward \(0\).
  • Action \(\text{left}\) transitions back to state \(s\) with reward \(0\) with probability \(0.9\), and to terminal state \(T\) with reward \(+1\) with probability \(0.1\).
  • Target policy \(\pi\): Always chooses \(\text{left}\) (\(\pi(\text{left} \mid s) = 1, \pi(\text{right} \mid s) = 0\)). Under \(\pi\) with \(\gamma = 1\), \(v_\pi(s) = 1\).
  • Behavior policy \(b\): Chooses \(\text{left}\) and \(\text{right}\) with equal probability (\(b(\text{left} \mid s) = 0.5, b(\text{right} \mid s) = 0.5\)).

Consider episodes that consist of \(k\) consecutive \(\text{left}\) actions followed by termination with reward \(+1\).
Under behavior policy \(b\), the probability of observing an episode with \(k\) \(\text{left}\) actions ending in reward \(+1\) is: \[ \Pr_b(k) = (0.5)^k \times (0.1 \times 0.5) = 0.1 \times (0.5)^{k+1} \] The importance sampling ratio for such an episode is: \[ \rho = \prod_{i=1}^{k} \frac{\pi(\text{left} \mid s)}{b(\text{left} \mid s)} = \left(\frac{1}{0.5}\right)^k = 2^k \] The return for this episode is \(G = 1\). Thus, \(\rho G = 2^k\).

Evaluating the Second Moment \(\mathbb{E}_b[(\rho G)^2]\): \[ \mathbb{E}_b[(\rho G)^2] = \sum_{k=0}^{\infty} \Pr_b(k) \cdot (\rho G)^2 = \sum_{k=0}^{\infty} \Big(0.1 \times 0.5^{k+1}\Big) \cdot \Big(2^k\Big)^2 \] \[ = 0.05 \sum_{k=0}^{\infty} (0.5)^k \cdot 4^k = 0.05 \sum_{k=0}^{\infty} 2^k = \mathbf{\infty} \] Because the second moment diverges to infinity, the variance \(\text{Var}(\rho G) = \mathbb{E}_b[(\rho G)^2] - (\mathbb{E}_b[\rho G])^2 = \infty - 1 = \mathbf{\infty}\).

Conclusion: Ordinary importance sampling has infinite variance in this simple MDP. This formally proves why ordinary IS can fail to converge in finite time, necessitating Weighted Importance Sampling.

9.9 Incremental Implementation of Weighted Importance Sampling

9.9.1 Incremental Derivation

Suppose we observe a sequence of returns \(G_1, G_2, \ldots, G_n\) with corresponding importance weights \(W_1, W_2, \ldots, W_n\).
The weighted estimate after \(n-1\) returns is: \[ V_n = \frac{\sum_{k=1}^{n-1} W_k G_k}{\sum_{k=1}^{n-1} W_k}, \quad n \ge 2 \] Let \(C_n = \sum_{k=1}^{n} W_k\) be the cumulative sum of weights. The update rule for \(V_{n+1}\) upon receiving weight \(W_n\) and return \(G_n\) is: \[ V_{n+1} = V_n + \frac{W_n}{C_n} \Big[ G_n - V_n \Big], \quad n \ge 1 \] where \(C_n = C_{n-1} + W_n\) with \(C_0 = 0\).

9.9.2 Numerical Step-by-Step Trace

Suppose weighted returns arrive as \((W, G) = (2, 5), (1, 2), (3, 4)\). Initialize \(V_1 = 0, C_0 = 0\).

Observation \((W, G)\)Cumulative Weight \(C_n\)Incremental Update FormulaNew Estimate \(V_{n+1}\)
\((2, 5)\)\(C_1 = 0 + 2 = 2\)\(V_2 = 0 + \frac{2}{2}(5 - 0)\)5.0
\((1, 2)\)\(C_2 = 2 + 1 = 3\)\(V_3 = 5 + \frac{1}{3}(2 - 5) = 5 - 1\)4.0
\((3, 4)\)\(C_3 = 3 + 3 = 6\)\(V_4 = 4 + \frac{3}{6}(4 - 4) = 4 + 0\)4.0

Verification with Batch Calculation: \[ V_{\text{batch}} = \frac{W_1 G_1 + W_2 G_2 + W_3 G_3}{W_1 + W_2 + W_3} = \frac{2(5) + 1(2) + 3(4)}{2 + 1 + 3} = \frac{10 + 2 + 12}{6} = \frac{24}{6} = \mathbf{4.0} \] The incremental update matches the batch result exactly!

9.10 The Off-Policy MC Control Algorithm

9.10.1 Deterministic Target Policy & Break Condition

In Off-Policy MC Control, the target policy \(\pi\) is maintained as deterministic greedy with respect to \(Q\): \[ \pi(s) = \arg\max_a Q(s, a) \] Since \(\pi(A_t \mid S_t)\) is \(1\) if \(A_t = \pi(S_t)\) and \(0\) if \(A_t \neq \pi(S_t)\), the importance sampling ratio becomes zero whenever the behavior action disagrees with the target policy action.

The Break Condition: If \(A_t \neq \pi(S_t)\), the algorithm immediately exits the inner episode loop. Earlier state-action pairs in that episode receive weight \(0\), so no further updates are performed for that episode.

9.10.2 Algorithm Pseudocode

Initialize, for all s ∈ S, a ∈ A(s):
    Q(s, a) ∈ ℜ (arbitrarily)
    C(s, a) ← 0
    π(s) ← argmax_a Q(s, a)

Loop forever (for each episode):
    b ← any soft policy with coverage of π
    Generate an episode using b: S_0, A_0, R_1, S_1, A_1, R_2, ..., S_T
    G ← 0
    W ← 1
    Loop for each step of episode, t = T-1, T-2, ..., 0:
        G ← γ * G + R_{t+1}
        C(S_t, A_t) ← C(S_t, A_t) + W
        Q(S_t, A_t) ← Q(S_t, A_t) + (W / C(S_t, A_t)) * [G - Q(S_t, A_t)]
        π(S_t) ← argmax_a Q(S_t, a)
        If A_t ≠ π(S_t) then exit inner loop
        W ← W * (1 / b(A_t | S_t))

9.10.3 Worked Walkthrough: Line World Control

Line World Setup (Section 8.2 in Lecture Notes): States: \(w, x, y, z\). Exits from \(w\) (reward \(-100\)) and \(z\) (reward \(+10\)). From \(x\) and \(y\), actions are \(L, R\). Discount \(\gamma = 0.9\). Behavior policy \(b(L)=b(R)=0.5\).

Episode 1 under \(b\): \(x \xrightarrow{R, 0} y \xrightarrow{R, 0} z \xrightarrow{\text{Exit}, +10} T\)
Backward scan (\(t=2, 1, 0\)):
  • At \(z\) (\(t=2\)): \(G = 10 \implies Q(z, \text{Exit}) = 10, C(z, \text{Exit}) = 1\). \(\pi(z) = \text{Exit}\). \(W \leftarrow 1 \times \frac{1}{1} = 1\).
  • At \(y\) (\(t=1\)): \(G = 0 + 0.9(10) = 9 \implies Q(y, R) = 9, C(y, R) = 1\). \(\pi(y) = R\). Since \(A_1 = R = \pi(y)\), continue! \(W \leftarrow 1 \times \frac{1}{0.5} = 2\).
  • At \(x\) (\(t=0\)): \(G = 0 + 0.9(9) = 8.1 \implies Q(x, R) = 8.1, C(x, R) = 2\). \(\pi(x) = R\).

Episode 2 under \(b\): \(x \xrightarrow{L, 0} w \xrightarrow{\text{Exit}, -100} T\)
  • At \(w\): \(G = -100 \implies Q(w, \text{Exit}) = -100\).
  • At \(x\): \(G = 0 + 0.9(-100) = -90 \implies Q(x, L) = -90\).
  • Target policy check at \(x\): \(Q(x, R) = 8.1 > Q(x, L) = -90 \implies \pi(x) = R\).
  • Observed action \(A_0 = L \neq \pi(x) = R \implies\) Exit inner loop!

Result: The target policy learns optimal deterministic path \(\pi(x)=R, \pi(y)=R\), ignoring sub-optimal exploratory actions taken by \(b\).

9.10.4 Worked Walkthrough: Five-State Grid Control

States \(A, B, C, D, E\). \(D\) exits with \(+10\), \(A\) exits with \(-10\), step penalty \(-1\). \(\gamma = 0.9\).
Episode 1: \(B \xrightarrow{E, -1} C \xrightarrow{E, -1} D \xrightarrow{\text{Exit}, +10} T \implies Q(C, E) = 8, \pi(C) = E\).
Episode 2: \(E \xrightarrow{N, -1} C \xrightarrow{N, -1} A \xrightarrow{\text{Exit}, -10} T \implies Q(C, N) = -10\). At \(C\), greedy choice is \(E\) (\(Q=8 > -10\)). Action \(N \neq \pi(C) \implies\) inner loop breaks! Target policy keeps \(\pi(C) = E\).

9.11 Advanced Off-Policy Ideas

9.11.1 Discounting-Aware Importance Sampling

Standard importance sampling applies a single ratio \(\rho_{t:T-1}\) to the entire return \(G_t\). If \(\gamma < 1\) and episodes are long, late rewards have negligible impact on \(G_t\), but their action ratios still multiply into \(\rho_{t:T-1}\), inflating variance unnecessarily. Discounting-aware IS decomposes the return by horizon to omit ratios for heavily discounted future steps.

9.11.2 Per-Decision Importance Sampling

Per-Decision Importance Sampling: Note that reward \(R_{t+k+1}\) depends only on decisions up to step \(t+k\). Therefore, it needs correction ratios only up to \(t+k\): \[ \tilde{G}_t = \sum_{k=0}^{T-t-1} \gamma^k \rho_{t:t+k} R_{t+k+1} = \rho_{t:t} R_{t+1} + \gamma \rho_{t:t+1} R_{t+2} + \ldots + \gamma^{T-t-1} \rho_{t:T-1} R_T \] By avoiding multiplying early rewards by later action ratios, per-decision IS significantly reduces variance in long episodes.

9.12 Real-World Applications of Off-Policy Learning

9.12.1 Logged Recommendation Systems

Reference: Chen, Beutel, Covington, Jain, Belletti, and Chi, "Top-K Off-Policy Correction for a REINFORCE Recommender System", ACM WSDM 2019.

In industrial recommendation (e.g., YouTube/Netflix), historical logs were generated by a production recommender (behavior policy \(b\)). The target policy \(\pi\) is a new neural model. Off-policy correction reweights logged clicks/watch-time to eliminate popularity bias and train \(\pi\) without live user risk.

9.12.2 Logged Bandit Feedback in Healthcare & Advertising

Reference: Dudik, Langford, and Li, "Doubly Robust Policy Evaluation and Learning", ICML 2011.

In medical treatment evaluation, historical treatments were chosen by clinicians (behavior policy). Evaluating a new treatment policy from medical records requires importance sampling to adjust for doctor preferences. Doubly robust estimators combine IS with outcome modeling for ultra-low variance.

9.13 Student Questions and Answers

Q: Why multiply the return by the importance sampling ratio? What is the intuition?

A (Professor): Think of three entities: teacher (behavior \(b\)), learner (target \(\pi\)), and exam authority (environment rewards). The teacher acts and gets a return. As the learner, you reason: "The teacher took these actions and earned this return. But I act differently — taking some actions more often and others less." If you would take an action more often than the teacher, multiply by a factor \(> 1\). If less often, multiply by \(< 1\). That factor is \(\rho\).
Q: How are we learning \(\pi\) if we only observe data from \(b\)?

A (Professor): Target policy \(\pi\) is greedy with respect to \(Q\). Behavior policy \(b\) collects experience. After each episode, we update \(Q(s,a)\) using importance-weighted returns from \(b\), and re-orient \(\pi\) greedily towards the updated \(Q\). Thus, \(\pi\) improves continuously and can surpass \(b\).

9.14 Introduction to Temporal Difference (TD) Learning

TD(0) Learning: Updates value estimates after every single step by bootstrapping: \[ V(S_t) \leftarrow V(S_t) + \alpha \Big[ R_{t+1} + \gamma V(S_{t+1}) - V(S_t) \Big] \] Where \(R_{t+1} + \gamma V(S_{t+1})\) is the TD Target and \(\delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t)\) is the TD Error.

9.15 Review Questions and Practice Problems

1. Explain the difference between on-policy and off-policy Monte Carlo learning.
Solution: On-policy learning evaluates/improves the same policy that generates the data. Off-policy learning evaluates/improves a target policy \(\pi\) using data generated by a separate behavior policy \(b\).
2. State the coverage assumption. Why is it necessary?
Solution: \(\pi(a \mid s) > 0 \implies b(a \mid s) > 0\) for all \(s, a\). If \(b(a \mid s) = 0\) when \(\pi(a \mid s) > 0\), the behavior policy will never sample action \(a\), leaving no data to estimate its value under \(\pi\).
3. Show how environment dynamics cancel out in the trajectory ratio.
Solution: \(\rho = \frac{\prod \pi(A_k \mid S_k) p(S_{k+1} \mid S_k, A_k)}{\prod b(A_k \mid S_k) p(S_{k+1} \mid S_k, A_k)} = \prod \frac{\pi(A_k \mid S_k)}{b(A_k \mid S_k)}\). The transition probabilities \(p(S_{k+1} \mid S_k, A_k)\) are identical in numerator and denominator.
4. Compute \(\rho\) for \(\pi(a_1 \mid s) = 0.8, b(a_1 \mid s) = 0.4, \pi(a_2 \mid s') = 0.3, b(a_2 \mid s') = 0.6\).
Solution: \(\rho = \left(\frac{0.8}{0.4}\right) \times \left(\frac{0.3}{0.6}\right) = 2 \times 0.5 = \mathbf{1.0}\).
5. Returns \(G_1 = 6, G_2 = 2\) with ratios \(\rho_1 = 4, \rho_2 = 0.5\). Compute OIS and WIS.
Solution: \(V^{OIS} = \frac{4(6) + 0.5(2)}{2} = \frac{25}{2} = \mathbf{12.5}\). \(V^{WIS} = \frac{4(6) + 0.5(2)}{4 + 0.5} = \frac{25}{4.5} \approx \mathbf{5.56}\).
6. Why can Ordinary IS yield estimates far outside the range of observed returns?
Solution: Ordinary IS divides by \(N\) (episode count) instead of the sum of weights. A single trajectory with a large \(\rho\) inflates the numerator without scaling the denominator, pulling the average far above any observed return.
7. Give an example episode where First-Visit and Every-Visit use different sample counts.
Solution: Episode \(A \to B \to A \to T\). First-visit uses only the first occurrence of \(A\) (\(t=0\)). Every-visit uses both occurrences (\(t=0\) and \(t=2\)).
8. Why is Weighted IS biased in finite samples but preferred in practice?
Solution: The denominator \(\sum \rho_i\) is a random variable, introducing finite-sample bias. However, normalization bounds estimates to the range of returns, dramatically reducing variance compared to Ordinary IS.
9. Explain the infinite variance proof for the one-state MDP.
Solution: In the 1-state MDP, taking \(k\) left actions yields ratio \(2^k\) with probability \(0.1 \times 0.5^{k+1}\). The second moment \(\mathbb{E}_b[(\rho G)^2] = 0.05 \sum 2^k = \infty\), proving variance is infinite.
10. In off-policy MC control, why stop the backward scan when \(A_t \neq \pi(S_t)\)?
Solution: Target policy \(\pi\) is deterministic greedy. If \(A_t \neq \pi(S_t)\), then \(\pi(A_t \mid S_t) = 0\), making \(\rho = 0\) for all earlier time steps. Further updates in that episode would have zero weight.
11. Uniform behavior policy over 4 actions. Deterministic target policy. Compute \(\rho\) for 3 target steps.
Solution: Per step ratio \(= \frac{1}{1/4} = 4\). For 3 steps, \(\rho = 4^3 = \mathbf{64}\).
12. Line World trace: \(x \xrightarrow{R, 0} y \xrightarrow{R, 0} z \xrightarrow{\text{Exit}, +10} T\) with \(\gamma = 0.9\). Compute returns.
Solution: At \(z\): \(G=10\). At \(y\): \(G=0+0.9(10)=9\). At \(x\): \(G=0+0.9(9)=8.1\).
13. Difference between trajectory IS and per-decision IS?
Solution: Trajectory IS applies the full ratio \(\rho_{t:T-1}\) to the whole return. Per-decision IS applies ratios only up to each reward's step (\(\rho_{t:t+k}\) for \(R_{t+k+1}\)), reducing variance.
14. Formulate off-policy evaluation for a recommender system.
Solution: State \(s\): user context/history. Action \(a\): recommended item slate. Reward \(r\): click/watch time. Behavior \(b\): old recommender. Target \(\pi\): new model. Importance sampling corrects for historical recommendation bias.
15. Medical decision system evaluation: Why off-policy?
Solution: Behavior policy \(b\) represents past doctor decisions. Target policy \(\pi\) is a new treatment guideline. Off-policy evaluation measures \(\pi\)'s expected clinical outcome without executing untested treatments on live patients.

9.16 Exam Guidance Summary

Exam Essentials:
  1. Manual \(\rho\) calculation: Multiply per-step ratios \(\frac{\pi(a \mid s)}{b(a \mid s)}\). Remember dynamics cancel out!
  2. OIS vs WIS formulas: OIS divides by \(N\); WIS divides by \(\sum \rho_i\).
  3. Off-Policy Control Scan: Work right-to-left, update \(C(s,a) \leftarrow C + W\), \(Q \leftarrow Q + \frac{W}{C}(G - Q)\), and break immediately if \(A_t \neq \pi(S_t)\).
  4. Infinite Variance Proof: Be prepared to write down the 1-state MDP geometric series summation \(\sum 2^k = \infty\).

9.17 Key Takeaways

  1. Off-policy learning decouples exploration (behavior policy \(b\)) from optimization (target policy \(\pi\)).
  2. Importance sampling corrects distribution mismatch via ratio \(\rho_{t:T-1}\); environment transition probabilities cancel completely.
  3. Weighted IS is far more stable than Ordinary IS because normalization bounds returns and eliminates infinite variance issues in practice.
  4. Off-Policy MC Control uses weighted incremental updates and breaks backward scans on action mismatch.
  5. Per-decision IS reduces variance by scaling each reward only by action ratios up to its arrival.
  6. TD learning updates after every single step using bootstrapping \(R_{t+1} + \gamma V(S_{t+1})\).

Exam Revision Notes

Below is the distilled, exam-ready core of this lecture. Use this section for rapid review before tests.

On-Policy Monte Carlo Methods

Must-know: On-policy MC evaluates a policy by averaging complete returns from sampled episodes. The same policy \(\pi\) both generates experience and learns from it. First-visit MC is unbiased.

\[ V^\pi(s) = \mathbb{E}_\pi[G_t \mid S_t = s] \approx \frac{1}{N} \sum_{i=1}^{N} G_i(s) \]

Top pitfall: Confusing on-policy and off-policy — the presence of importance weights \(W\) and cumulative sum \(C\) signals off-policy.

Self-check: Why must the behavior policy in on-policy MC be \(\varepsilon\)-soft, and what would happen if it were purely greedy?

Connects to: Off-Policy MC, MC algorithm trace

Off-Policy Learning and Importance Sampling

Must-know: Off-policy learning separates behavior policy \(b\) from target policy \(\pi\). The importance sampling ratio corrects for distribution mismatch while transition probabilities cancel out.

\[ \rho_{t:T-1} = \prod_{k=t}^{T-1} \frac{\pi(A_k \mid S_k)}{b(A_k \mid S_k)} \]

Top pitfall: Computing \(\rho\) from the episode start instead of from the relevant step onward.

Self-check: If \(\pi(a_1|s_0)=0.8, b(a_1|s_0)=0.5, \pi(a_2|s_1)=0.7, b(a_2|s_1)=0.4\), compute \(\rho\) for trajectory \((s_0, a_1, s_1, a_2, s_0, a_1, T)\).

Connects to: Weighted IS, Coverage condition

Ordinary vs. Weighted Importance Sampling

Must-know: Weighted importance sampling is preferred in practice — denominator uses sum of weights not \(N\). Yields dramatically lower variance with negligible initial bias.

\[ V^\pi(s)_{\text{weighted}} = \frac{\sum \rho_i G_i}{\sum \rho_i} \quad\text{vs.}\quad V^\pi(s)_{\text{ordinary}} = \frac{\sum \rho_i G_i}{N} \]

Top pitfall: Using ordinary IS formula when weighted IS is required, or using \(N\) as denominator of weighted IS.

Self-check: Two episodes give \(\rho_1=4, G_1=10\) and \(\rho_2=0.02, G_2=1\). Compute both ordinary and weighted IS estimates.

Connects to: Incremental average updates, Infinite Variance Proof

Proof of Infinite Variance in Ordinary IS

Must-know: Ordinary IS can have infinite variance even in simple 1-state MDPs because the second moment \(\mathbb{E}[(\rho G)^2]\) contains a diverging geometric series \(\sum_{k=0}^\infty 2^k = \infty\).

\[ \mathbb{E}_b[(\rho G)^2] = \sum_{k=0}^{\infty} 0.5^{k+1} (2^k)^2 = 0.5 \sum_{k=0}^{\infty} 2^k = \infty \]

Top pitfall: Thinking infinite variance means the estimator is mathematically biased; ordinary IS is unbiased but practically unusable due to extreme variance.

Self-check: Why does weighted IS avoid infinite variance in the 1-state example?

Connects to: Ordinary IS, Weighted IS

Off-Policy MC Control Algorithm

Must-know: Processes episodes right-to-left, accumulating \(G\) and \(W\). Updates \(Q(s,a)\) via weighted incremental average. Breaks when action disagrees with deterministic target policy.

\[ Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \frac{W}{C(S_t, A_t)}(G - Q(S_t, A_t)) \quad\text{with}\quad W \leftarrow W \times \frac{1}{b(A_t \mid S_t)} \]

Top pitfall: Forgetting to add \(W\) to \(C\) before updating \(Q\), or updating \(W\) after hitting the break condition.

Self-check: In Line-World control, why does an episode starting with action Left cause the inner loop to exit immediately?

Connects to: Weighted importance sampling, Deterministic target policy

Per-Decision & Discounting-Aware Importance Sampling

Must-know: Per-decision IS applies importance weights only up to each reward's step: \(\tilde{G}_t = \sum \gamma^k \rho_{t:t+k} R_{t+k+1}\), eliminating unnecessary variance from later action ratios.

\[ \tilde{G}_t = \sum_{k=0}^{T-t-1} \gamma^k \rho_{t:t+k} R_{t+k+1} \]

Top pitfall: Multiplying early rewards by full trajectory ratios \(\rho_{t:T-1}\) when using per-decision IS.

Self-check: Why does per-decision IS reduce variance compared to standard trajectory-level IS?

Connects to: Variance reduction, Discounting-aware IS

Temporal Difference (TD) Learning

Must-know: TD updates after every single step using bootstrapped target \(R_{t+1} + \gamma V(S_{t+1})\). Combines MC's model-free learning with DP's bootstrapping.

\[ V(S_t) \leftarrow V(S_t) + \alpha\big[R_{t+1} + \gamma V(S_{t+1}) - V(S_t)\big] \]

Top pitfall: Confusing the TD target (one-step reward plus bootstrapped value) with the full MC return (complete episode return).

Self-check: In what situations would you prefer TD over MC, and vice versa?

Connects to: On-policy MC, DP bootstrapping, SARSA and Q-learning
