Chapter 6: Syllabus Overview and Exam Preparation Guide

8.1 The Examinable Syllabus

This section provides a structured walkthrough of the topics covered up to Monte Carlo control, with guidance on what is expected for the midterm examination. The focus is on understanding, not memorisation.

8.1.1 Module 1: Introduction to Reinforcement Learning

  • Core skill: Given a real-world scenario, determine whether it is an RL problem. Identify if the problem involves an agent interacting with an environment, learning from rewards, and improving behaviour over time.
  • RL vs Supervised Learning: Be able to articulate why a given problem is better suited to RL than supervised learning, and vice versa. RL learns from interaction and delayed feedback; supervised learning learns from labelled examples.
  • Stationary vs Non-Stationary: Understand the implications of a changing world on learning. If the environment evolves, the agent must continuously adapt.
  • Tic-Tac-Toe Example: Study the value updates and how learning progresses through self-play. This example illustrates the core ideas of value-based learning in a simple setting.

8.1.2 Module 2: Multi-Armed Bandits

  • Modelling skill: Given a scenario (traffic signals, medical trials, market basket), identify the arms, actions, and rewards. Map the real problem to the MAB abstraction.
  • Action-value methods: Incremental update rules, tracking non-stationarity with constant step-size α instead of 1/n. Understand when each is appropriate.
  • Optimistic initial values: Know why this is a hack that biases early exploration, when it works, and its limitations as a general technique.
  • Upper Confidence Bound (UCB): This is a crucial idea for the entire course. Be able to write the UCB expression, explain each term, and solve numerical problems. UCB balances exploitation (high estimated value) with exploration (high uncertainty).
  • Contextual Bandits: Distinguish between classic MAB, contextual bandits, and full RL. In contextual bandits, the agent observes a context before choosing an action. In full RL, actions affect future states. Be able to tag a scenario into one of these three categories.

8.1.3 Module 3: Markov Decision Processes

  • Modelling skill: Given any full RL scenario, identify the MDP elements: states, actions, rewards, transition probabilities, and discount factor. Write them down explicitly.
  • Bellman Equations: There are two versions studied. The expected update (Bellman expectation equation) expresses Vπ in terms of the policy's action probabilities and the model dynamics. The optimal update (Bellman optimality equation) uses max over actions. Be able to write a custom Bellman equation for any given scenario — do not just copy the generic formula. Annotate it with the actual state and action names from the problem.
  • Stochastic outcomes: When both transitions and rewards are stochastic, the role of model dynamics in the Bellman update becomes explicit. The expected value weights each possible outcome by its probability.
  • Optimal values and policies: Understand the relationship between optimal value functions and optimal policies. The optimal policy is greedy with respect to the optimal value function.

8.1.4 Module 4: Dynamic Programming

  • Policy evaluation (prediction): Compute Vπ for a given policy iteratively using the Bellman expectation equation as an update rule.
  • Value iteration: This has been the numerical focus in class. Understand both in-place (asynchronous) and not-in-place (synchronous) updates. Some exam questions may use the term "asynchronous dynamic programming" when they expect an in-place update. Navigate this terminology carefully.
  • Policy iteration: Understand conceptually, but value iteration has been the primary computational focus for the exam.

8.1.5 Module 5: Monte Carlo Methods (Current Module)

  • Prediction (on-policy): First-visit and every-visit MC estimation of Vπ(s) and Qπ(s,a). Be able to compute returns and value estimates from given episodes.
  • Control (on-policy): Epsilon-greedy MC control without exploring starts. Initialise with an epsilon-soft policy, converge through epsilon-greedy updates. The policy at each step is epsilon-greedy with respect to the current Q-values.
  • Off-policy MC: Not included in the midterm syllabus, but understand the conceptual distinction between on-policy and off-policy methods.
Exam Tip — Write Explicit Policies: When a question asks you to compute a revised policy from Q-values, write the explicit probabilities. Do not just list the dominant actions. For each state, write out π(a|s) for every action using the epsilon-greedy formula. Show your working: (1 - ε) for the greedy action plus its epsilon share, and ε/|A(s)| for each non-greedy action.
Exam Tip — Track Returns Properly: When working through a control example by hand, always maintain the list of returns for each state-action pair. The Q-value is the average of all returns in that list. After the first episode, Q equals the single return. After subsequent episodes, Q is the running average. If you skip the list and just use the latest return, you are computing something else entirely.

8.2 How to Prepare Effectively

Key Principle: This is a postgraduate course. The examination values understanding over pattern-matching. Do not rely on solving many sample question papers. Instead, make sure you can explain every concept in your own words, map real scenarios to the right abstraction, and work through numerical examples from scratch without referring to notes.

Recommended approach:

  1. For each module, take a blank sheet of paper and write down every concept, formula, and algorithm covered. Do this from memory first, then check against the textbook.
  2. Practice modelling: take any random scenario (a robot navigating a building, a stock trading bot, a game AI) and write down its MDP elements. Can you also model it as MAB? As a contextual bandit? Understanding these boundaries is a key skill.
  3. For numerical sections (DP value iteration, MC prediction, MC control), work through the textbook examples by hand without looking at the solution. Then verify your answers.
  4. For the Bellman equations, practice writing custom versions for specific scenarios. Do not just memorise the generic form — the exam will ask you to apply it to a concrete problem.
  5. Prepare your time well. Do not leave everything until the last night. Sleep and health matter for performance.
The syllabus up to on-policy Monte Carlo control spans the full spectrum. It goes from problem modelling (MDPs) to planning (DP) to learning from interaction (MC methods). Each module builds on the previous one. Master the progression: MAB → contextual bandits → full RL, and MDP modelling → Bellman equations → DP planning → MC learning. This conceptual thread is what the examination tests.

8.3 Beyond the Exam: What Comes Next

The modules covered so far form the foundation. After the midterm, the course will extend into off-policy Monte Carlo methods, temporal-difference learning, and function approximation. The intuition you build now — especially around exploration, the role of Q-values, and the behaviour-target distinction — will carry through the entire remainder of the course.

Preview: Temporal-Difference Learning (Chapter 6, Sutton & Barto): TD learning is the single most central and novel idea in reinforcement learning. It combines the sampling of Monte Carlo methods with the bootstrapping of DP. Like MC, TD methods learn directly from raw experience without a model. Like DP, TD methods update estimates based in part on other learned estimates, without waiting for a final outcome.

The simplest TD method, TD(0), updates V(St) using the observed reward Rt+1 and the current estimate V(St+1): V(St) ← V(St) + α[Rt+1 + γV(St+1) − V(St)]. Unlike MC, which must wait until the end of an episode, TD learns immediately after each transition. This makes TD naturally suited for on-line, incremental learning and for continuing tasks with no episodes.

TD methods converge to vπ for any fixed policy π, and in practice they usually converge faster than constant-α MC on stochastic tasks. Under batch training (repeatedly processing a fixed set of episodes), TD(0) converges to the certainty-equivalence estimate — the value function that would be exactly correct for the maximum-likelihood model of the Markov process — while MC converges to the minimum squared-error estimate on the training data.
Solving Blackjack with Monte Carlo ES (Example 5.3, Sutton & Barto):

Applying Monte Carlo ES to blackjack is straightforward. Since episodes are simulated games, exploring starts are easy: pick the dealer's cards, player's sum, and usable ace status all at random. The initial policy sticks only on 20 or 21. All Q-values start at zero. After many episodes, the algorithm converges to the optimal policy — which turns out to be the same as Thorp's (1966) "basic" strategy, with one minor exception in the usable-ace region. The state-value function v*(s) computed from the action-value function shows that states with a player sum of 20 or 21 and a low dealer showing card have positive expected value (the player is likely to win), while low sums against high dealer cards are negative. This is a concrete demonstration that MC methods can find optimal policies from pure simulation without any model of the environment's transition probabilities.

The early history of reinforcement learning, while not part of the exam syllabus, is worth reading when time permits. Understanding how these ideas evolved from psychology, optimal control, and early AI provides a richer perspective on why the algorithms are designed the way they are.
