Gaussian Mixture Models and Support Vector Machines

This lecture covers two major machine learning approaches. The first half introduces Gaussian Mixture Models (GMM) — a soft clustering technique that extends K-means into a probabilistic framework. The second half introduces Support Vector Machines (SVM) — a supervised classification algorithm that finds the hyperplane with the maximum separating margin between classes. Both are foundational tools used across data science, from customer segmentation to medical diagnosis.

16.1 Context — From K-Means to Gaussian Mixture Models

What if your clusters overlap — if a data point could reasonably belong to two groups at once? K-means forces a binary yes/no answer. GMM gives a richer answer: "85% this group, 10% that group, 5% the other." This section builds the bridge from hard clustering to soft, probabilistic clustering.

16.1.1 Recap of K-Means Clustering

K-means is a clustering algorithm. It groups data objects into clusters by allocating every data object to exactly one cluster — "this point belongs to cluster one, that point belongs to cluster two." This assignment may change across iterations, but at every moment the algorithm declares a definite, exclusive cluster membership for each point.

This is called hard clustering. Each point gets a binary label: in or out. There is no middle ground.

The K-means algorithm works by minimizing a distortion measure: the sum of squared distances from each point to its assigned cluster center. It alternates between two steps: (E-step) assign each point to the nearest center, and (M-step) recompute each center as the mean of its assigned points. This two-stage iteration repeats until assignments stop changing. The same E-step/M-step language carries forward to GMM, which is why the professor introduces it: "It is exactly K-means extension. That is why we learned K-means first."

K-means objective (distortion measure): \[ J = \sum_{n=1}^{N} \sum_{k=1}^{K} r_{nk} \| \mathbf{x}_n - \boldsymbol{\mu}_k \|^2 \] where \(r_{nk} \in \{0,1\}\) is a binary indicator — 1 if point \(n\) is assigned to cluster \(k\), 0 otherwise. \(\boldsymbol{\mu}_k\) is the center (prototype) of cluster \(k\). This is the standard formulation from the reference text (Bishop §9.1).

16.1.2 Why Remove Duplicates Before Clustering

Pitfall: Running clustering on data with many duplicate records biases the statistical description of the data.

If you have 100 copies of one record and 100 unique records, the mean gets pulled toward the repeated values. That one repeated record gains disproportionately large influence. The statistical description — the mean, the spread — gets warped, and from there it influences everything downstream: cluster centers, variance estimates, and ultimately the cluster assignments themselves. The professor emphasized: "The statistical description itself gets warped, and from there it influences everything downstream."

16.1.3 Introducing Gaussian Mixture Models (GMM)

A Gaussian Mixture Model (GMM) is a probabilistic model for clustering. Unlike K-means, which groups points by distance, GMM assumes that all data points are generated from a mixture of several Gaussian (bell-curve) distributions with unknown parameters.

The professor's central analogy is reverse engineering:

"If I had to recreate this exact dataset using a few bell curves, where would I place those bell curves? How wide would they be?"

If you try to draw a single Gaussian through the entire dataset, it will not capture the underlying structure. But if the data has distinct groups, you can place one Gaussian over each group. The question GMM answers is: where should these Gaussians go, how wide should they be, and how much does each one contribute?

A Gaussian Mixture Model with \(K\) components has the probability density: \[ p(\mathbf{x}) = \sum_{k=1}^{K} \pi_k \cdot \mathcal{N}(\mathbf{x} \mid \boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k) \] where \(\pi_k\) is the mixing coefficient (weight) of component \(k\), satisfying \(\sum_{k=1}^{K} \pi_k = 1\), and \(\mathcal{N}(\mathbf{x} \mid \boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k)\) is the multivariate Gaussian PDF with mean \(\boldsymbol{\mu}_k\) and covariance \(\boldsymbol{\Sigma}_k\). This is the standard formulation from Bishop §9.2.

16.1.4 Why Not a Single Gaussian?

Imagine a dataset of adult heights in a city. The data comes from two underlying distributions — men's heights (mean ~175 cm) and women's heights (mean ~162 cm). A person who is 168 cm tall could be a tall woman or an average-height man. A single Gaussian would smear both groups into one blob, losing this structure. You need two overlapping bell curves.

This height example is not just pedagogical — it is a classic real-world use of GMM: discovering latent groups (male/female) from unlabeled data without ever knowing the gender labels. GMM captures this by modeling the data as coming from multiple distributions, each with its own mean, variance, and weight.

K-means asks "which cluster?" with a binary answer. GMM asks "how much of each cluster?" with probabilities. This soft assignment is the fundamental upgrade — and it lets GMM handle overlapping, elliptical clusters that K-means cannot.

16.2 Gaussian Mixture Model — Core Concepts

Think of a dart board with two bullseyes. Some darts cluster around the first bullseye, some around the second, and a few land in between. Hard clustering forces you to assign each dart to exactly one bullseye. Soft clustering (GMM) lets you say: "This dart is 70% from player A, 30% from player B." Now imagine the dart clusters aren't even round — they're oval-shaped because one player throws with a sideways drift. GMM handles that too.

16.2.2 Flexibility in Cluster Shape

K-means has one implicit assumption that severely limits it: clusters are spherical. GMM lifts this restriction.

K-means only cares about the Euclidean distance from each center. It assumes equal variance in all directions — clusters are circles (in 2D) or spheres (in higher dimensions). If you have two elongated, cigar-shaped clusters that overlap, K-means cannot identify them correctly. It will cut through them with a straight bisector and produce wrong assignments.

GMM is more flexible because it models three things per component:

  • Mean \(\boldsymbol{\mu}_k\) — the center of each Gaussian (same idea as K-means centroids).
  • Variance — how much a single variable spreads around the mean. Large variance = wide bell curve.
  • Covariance — how two variables move together. If height and weight are positively correlated (taller people tend to be heavier), the covariance captures that tilt.

The covariance matrix \(\boldsymbol{\Sigma}_k\) encodes both variances and covariances:

\[ \boldsymbol{\Sigma}_k = \begin{bmatrix} \sigma_{XX}^2 & \sigma_{XY} \\ \sigma_{YX} & \sigma_{YY}^2 \end{bmatrix} \]
  • Diagonal entries (\(\sigma_{XX}^2, \sigma_{YY}^2\)): variance along each axis — controls spread.
  • Off-diagonal entries (\(\sigma_{XY}, \sigma_{YX}\)): covariance between axes — controls tilt and shape.

Together, these parameters allow GMM to form elliptical clusters of arbitrary orientation, not just circles. The bell curve can be stretched, squeezed, and rotated to fit the data.

Visual intuition: Imagine looking down from above at the bell curves (the professor's "top view"). For a circular cluster, the contour lines are concentric circles — like a target. For an elliptical cluster, the contours are concentric ellipses — like a tilted stretched target. GMM can produce either shape depending on the covariance matrix.

16.2.3 The Core Idea — Data as a Mixture of Gaussians

The fundamental assumption of GMM: the dataset is an additive mixture — a weighted sum of contributions from multiple Gaussian distributions.

If the data has three distinct groups, GMM assumes three separate underlying Gaussians. The final dataset is a combination (mixture) of points drawn from these three curves. Some points come from Gaussian 1, some from Gaussian 2, some from Gaussian 3. The mixing coefficient \(\pi_k\) tells you what fraction of all data points come from Gaussian \(k\).

The professor contrasted this with models that assume all data comes from a single distribution: "This is fundamentally different from models that assume all data comes from a single distribution or a single group."

Scope: GMM assumes the data is generated from a finite mixture of Gaussians. If the true data distribution is not well-approximated by a sum of bell curves — for instance, it has sharp cutoffs, exponential tails, or uniform segments — GMM may need many components to fit well. It may even be the wrong model entirely. GMM also assumes the number of components \(K\) is known in advance — choosing \(K\) is a separate problem covered in §16.6.
GMM upgrades K-means in two ways: (1) soft probabilistic assignments instead of hard binary ones, and (2) elliptical cluster shapes instead of only spherical ones. The cost: you now need to fit means, covariances, and mixing weights — more parameters, more computation, but far more expressive clusters.

16.3 The GMM Algorithm — Expectation-Maximization

How do you find the best Gaussians when you don't know which points belong to which Gaussian — and you don't know where the Gaussians are? It sounds like a chicken-and-egg problem. The EM algorithm solves it by cycling between "guess which points go where" and "recenter the Gaussians based on the guess." Each cycle improves the fit.
Purpose: The Expectation-Maximization (EM) algorithm finds the maximum-likelihood estimates of the GMM parameters (\(\mu_k, \sigma_k^2, \pi_k\) for all \(k\)) when the cluster assignments are unknown (latent). It is the standard algorithm for fitting Gaussian mixture models.
Inputs & Outputs:
  • Input: Dataset \(\{x_1, x_2, \ldots, x_n\}\) of \(n\) points; number of components \(K\).
  • Output: For each component \(k\): mean \(\mu_k\), variance \(\sigma_k^2\), mixing weight \(\pi_k\). Plus soft assignments (responsibilities \(r_{ik}\)) for every point.

16.3.1 Algorithm Overview (Conceptual)

The EM algorithm for GMM alternates between two steps. The professor described them with a coloring analogy that captures the intuition perfectly:

  1. Initialization — Start with random Gaussians. Pick values for the mean (\(\mu\)) and standard deviation (\(\sigma\)) for each Gaussian you assume exists. If \(K = 2\), pick \(\mu_1, \sigma_1, \mu_2, \sigma_2\).
  2. E-step (Expectation) — "Color the points." For every data point, calculate what percentage it belongs to each Gaussian. A point may be 99% blue (component 1) and 1% green (component 2). No point is ever 100% one cluster — that is the fundamental difference from K-means.
  3. M-step (Maximization) — "Recalculate the Gaussians." Using the points now assigned (with their percentage weights), recompute the mean, variance, and mixing weight for each Gaussian. The Gaussians shift closer to the data they represent.
  4. Repeat until convergence — when assignments stop changing between two consecutive iterations.

16.3.2 Visual Analogy — The "Coloring" Process

The professor drew concentric circles to represent each Gaussian — these are the "top view" of bell curves, as if looking down from above. The circles represent contours of equal probability density.

Initially, the Gaussians are placed randomly. Points closer to Gaussian 1 get colored mostly blue. Points closer to Gaussian 2 get colored mostly green. Points equally close get half-and-half.

After coloring, the Gaussians are recalculated — they move to better fit the points assigned to them. Then the coloring changes because the Gaussians moved. This cycle continues until stable.

"If you understood the concept, it is very easy, but if you simply try to by-heart the formula 100 percentage, you will miss one or other step. What is that coloring example? Keep in mind, we can do that. You'll be able to solve any given problem."

16.3.3 Formal Algorithm Steps

Step 1 — Initialization:

Choose the number of Gaussians \(K\). Randomly initialize parameters for each Gaussian \(k = 1, 2, \ldots, K\):

  • Mean \(\mu_k\) (in 1D; or vector \(\boldsymbol{\mu}_k\) in multivariate)
  • Variance \(\sigma_k^2\) (in 1D; or covariance matrix \(\boldsymbol{\Sigma}_k\) in multivariate)
  • Mixing coefficient \(\pi_k = 1/K\) (start with equal weights)

In practice, Python libraries like scikit-learn run K-means first to get good initial centers, then use the resulting cluster means, covariances, and proportions as the starting GMM parameters.

Step 2 — E-step (Expectation): Compute responsibilities

The responsibility \(r_{ik}\) is the probability that data point \(i\) belongs to component \(k\):

\[ r_{ik} = \frac{\pi_k \cdot \mathcal{N}(x_i \mid \mu_k, \sigma_k^2)}{\sum_{j=1}^{K} \pi_j \cdot \mathcal{N}(x_i \mid \mu_j, \sigma_j^2)} \]

What each part means:

  • Numerator: \(\pi_k \cdot \mathcal{N}(x_i \mid \mu_k, \sigma_k^2)\) — "prior weight of cluster \(k\)" times "how likely point \(i\) is under Gaussian \(k\)."
  • Denominator: sum of the same quantity over ALL clusters — normalizes so that \(\sum_{k=1}^{K} r_{ik} = 1\) for each point \(i\).
  • Result: For each point \(i\), you get a probability distribution over the \(K\) clusters. \(r_{ik} \in [0,1]\) always.

This formula is Bayes' theorem in action: it computes the posterior probability of cluster membership given the data. In Bishop's notation (§9.2), this is \(\gamma(z_{nk})\), the responsibility of component \(k\) for data point \(n\).

Step 3 — M-step (Maximization): Update parameters using weighted data \[ \mu_k^{\text{new}} = \frac{\sum_{i=1}^{n} r_{ik} \cdot x_i}{\sum_{i=1}^{n} r_{ik}} \] \[ \sigma_k^{2,\text{new}} = \frac{\sum_{i=1}^{n} r_{ik} \cdot (x_i - \mu_k^{\text{new}})^2}{\sum_{i=1}^{n} r_{ik}} \] \[ \pi_k^{\text{new}} = \frac{1}{n} \sum_{i=1}^{n} r_{ik} \]

Why each update makes sense:

  • New mean: A weighted average of all data points, where each point's contribution is weighted by \(r_{ik}\) — how strongly it belongs to cluster \(k\). Points that are 95% in cluster \(k\) pull the mean much harder than points that are 5% in cluster \(k\).
  • New variance: A weighted variance — same weighting logic. Measures the spread of points around the new mean, weighted by membership strength.
  • New mixing coefficient: The average responsibility across all points. If many points belong strongly to cluster \(k\), \(\pi_k\) will be large; if cluster \(k\) is tiny, \(\pi_k\) will be small. This is exactly: total effective points in cluster \(k\) divided by \(n\).
Step 4 — Convergence check:

Stop when the log-likelihood of the data stops improving significantly:

\[ \text{Stop when } |\mathcal{L}^{(t+1)} - \mathcal{L}^{(t)}| < \varepsilon \]

where \(\mathcal{L} = \sum_{i=1}^{n} \ln\left( \sum_{k=1}^{K} \pi_k \cdot \mathcal{N}(x_i \mid \mu_k, \sigma_k^2) \right)\) is the log-likelihood of the observed data under the current GMM parameters, and \(\varepsilon\) is a small threshold (e.g., \(10^{-3}\)).

Equivalent stopping conditions: parameters change by less than \(\varepsilon\); no point changes its most-likely cluster assignment between iterations. All three are practically telling the same thing — the model has stopped improving.

Trace on a tiny dataset:

Consider \(n = 4\) points: \(\{0, 1, 2, 3\}\) with \(K = 2\).

Initialization: \(\mu_1 = 0.5, \sigma_1^2 = 1, \pi_1 = 0.5\); \(\mu_2 = 2.5, \sigma_2^2 = 1, \pi_2 = 0.5\).

E-step (Iteration 1): Compute \(r_{i1}, r_{i2}\) for each point using the responsibility formula.

  • Point 0: close to \(\mu_1 = 0.5\), far from \(\mu_2 = 2.5\) → \(r_{0,1} \approx 0.95\), \(r_{0,2} \approx 0.05\)
  • Point 3: close to \(\mu_2 = 2.5\), far from \(\mu_1 = 0.5\) → \(r_{3,1} \approx 0.05\), \(r_{3,2} \approx 0.95\)

M-step (Iteration 1): Recompute means using weighted averages.

\(\mu_1^{\text{new}} = \frac{0.95(0) + 0.80(1) + 0.20(2) + 0.05(3)}{0.95+0.80+0.20+0.05} \approx 0.65\) — shifted right toward its data.

\(\mu_2^{\text{new}}\) shifts left toward \(\{2,3\}\). The Gaussians tighten around their respective clusters.

Convergence: In the next E-step, the cluster assignments (0,1 → C1; 2,3 → C2) do not change, so the algorithm stops after 2 iterations. The full worked example is in §16.5.

Pitfalls:
  1. Local optima: EM is not guaranteed to find the global maximum of the likelihood. Different random initializations can lead to different final clusterings. In practice, run EM multiple times with different starting points and keep the best result (highest log-likelihood).
  2. Singularities: If a Gaussian component collapses onto a single data point, its variance can shrink to zero and the likelihood can blow up to infinity. This is a known issue with maximum-likelihood GMM (Bishop §9.2.1). Using a small regularization on the covariance or a Bayesian approach avoids this.
  3. Slow convergence: EM can take many iterations when clusters overlap heavily. The log-likelihood often improves rapidly in early iterations and then plateaus — don't mistake the plateau for convergence.
EM is the engine behind GMM. The E-step computes soft assignments (responsibilities). The M-step re-estimates parameters using those weighted assignments. Rinse and repeat. The professor's key insight: "Keep the coloring picture in mind and you'll be able to solve any given problem."

16.4 GMM — Mathematical Foundation

16.4.1 1D Gaussian Probability Density Function

The Gaussian (normal) probability density function (PDF) in one dimension, with mean \(\mu\) and variance \(\sigma^2\): \[ \mathcal{N}(x \mid \mu, \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(x - \mu)^2}{2\sigma^2}\right) \]

Every symbol named:

  • \(\mu\) (mu) — the mean, the center of the bell curve. "The average height."
  • \(\sigma\) (sigma) — the standard deviation, controls the spread. Larger \(\sigma\) = wider, flatter bell.
  • \(\sigma^2\) — the variance, the square of the standard deviation. "The spread of the heights."
  • \(\frac{1}{\sqrt{2\pi\sigma^2}}\) — the normalization constant. Ensures the total area under the curve equals 1.
  • \(\exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)\) — the exponential kernel. Measures how far \(x\) is from \(\mu\), scaled by the variance. When \(x = \mu\), this equals 1 (maximum). When \(x\) is far from \(\mu\), this drops toward 0.

The professor's plain-language summary: "The average height is the mean. The spread of the heights is the variance."

In 1D: the parameter is variance (\(\sigma^2\)). In multivariate: the parameter is covariance (\(\boldsymbol{\Sigma}\)).

16.4.2 Multivariate Gaussian Probability Density Function

For \(d\)-dimensional data \(\mathbf{x} \in \mathbb{R}^d\): \[ \mathcal{N}(\mathbf{x} \mid \boldsymbol{\mu}, \mathbf{\Sigma}) = \frac{1}{(2\pi)^{d/2} |\mathbf{\Sigma}|^{1/2}} \exp\left(-\frac{1}{2} (\mathbf{x} - \boldsymbol{\mu})^\top \mathbf{\Sigma}^{-1} (\mathbf{x} - \boldsymbol{\mu})\right) \]

Every symbol named:

  • \(d\) — number of dimensions (features). For 2D data like height and weight, \(d = 2\).
  • \(\mathbf{x}\) — a data point, a vector of length \(d\).
  • \(\boldsymbol{\mu}\) — the mean vector, also length \(d\). The center in \(d\)-dimensional space.
  • \(\boldsymbol{\Sigma}\) — the \(d \times d\) covariance matrix. Replaces the scalar \(\sigma^2\) from 1D. Its diagonal holds variances; off-diagonals hold covariances.
  • \(\boldsymbol{\Sigma}^{-1}\) — the inverse of the covariance matrix (the precision matrix).
  • \(|\boldsymbol{\Sigma}|\) — the determinant of \(\boldsymbol{\Sigma}\). A scalar measuring the "volume" of the covariance ellipsoid.
  • \((\mathbf{x} - \boldsymbol{\mu})^\top \boldsymbol{\Sigma}^{-1} (\mathbf{x} - \boldsymbol{\mu})\) — the squared Mahalanobis distance. This is the multivariate generalization of \(\frac{(x-\mu)^2}{\sigma^2}\). It measures distance from \(\mathbf{x}\) to \(\boldsymbol{\mu}\) in units of the covariance, accounting for correlations between dimensions.

Visual intuition: In 2D, \(\boldsymbol{\Sigma}\) determines the shape of equal-probability contours. When \(\boldsymbol{\Sigma} = \sigma^2 I\) (scaled identity), contours are circles. When \(\boldsymbol{\Sigma}\) has different diagonal values, contours are axis-aligned ellipses. When \(\boldsymbol{\Sigma}\) has non-zero off-diagonals, contours are rotated ellipses. The Mahalanobis distance is constant along each contour.

16.4.3 The GMM Probability Density Function

The overall PDF of a GMM with \(K\) components is an additive mixture — a weighted sum of \(K\) Gaussian densities: \[ p(\mathbf{x}) = \sum_{k=1}^{K} \pi_k \cdot \mathcal{N}(\mathbf{x} \mid \boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k) \] For the 1D case (exam-relevant): \[ p(x) = \sum_{k=1}^{K} \pi_k \cdot \frac{1}{\sqrt{2\pi\sigma_k^2}} \exp\left(-\frac{(x - \mu_k)^2}{2\sigma_k^2}\right) \] The mixing coefficients must satisfy: \[ \sum_{k=1}^{K} \pi_k = 1, \quad \pi_k \geq 0 \text{ for all } k \]

Why these constraints? \(\pi_k\) is the prior probability that a randomly chosen data point comes from component \(k\). As probabilities, they must sum to 1 and each must be non-negative.

The professor emphasized: "This is the formula you need to remember." \(p(x)\) is the probability density at position \(x\) — it tells you how likely you are to find a data point at that location. \(\pi_k\) represents the weight or relative size of each cluster. If cluster 1 is large (more data points), \(\pi_1\) might be 0.7 and \(\pi_2\) might be 0.3.

Derivation from the latent-variable viewpoint (Bishop §9.2): Each data point has an unobserved (latent) variable \(z\) indicating which component generated it. \(z\) uses a 1-of-\(K\) encoding: \(z_k = 1\) if point came from component \(k\), 0 otherwise. The joint distribution is \(p(\mathbf{x}, z) = p(z) p(\mathbf{x} \mid z)\). Marginalizing over \(z\) gives the mixture: \(p(\mathbf{x}) = \sum_z p(z) p(\mathbf{x} \mid z) = \sum_{k=1}^{K} \pi_k \mathcal{N}(\mathbf{x} \mid \boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k)\). This latent-variable formulation is what makes the EM algorithm possible.

16.5 GMM — Worked Example

This is the canonical exam-style problem. Work through every calculation step. The professor stated explicitly that 1D problems are what you should expect — 2D requires too much hand computation.

16.5.1 Problem Setup

Data: Four points: \(x_1 = 0\), \(x_2 = 1\), \(x_3 = 2\), \(x_4 = 3\)

Goal: Fit a mixture of \(K = 2\) Gaussian components. Run one full iteration of EM (E-step + M-step).

16.5.2 Step 1 — Initialization

Initial parameter guesses:
  • Component 1 (C1): \(\mu_1 = 0.5\) (mean of \(\{0, 1\}\)), \(\sigma_1^2 = 1\), \(\pi_1 = 0.5\)
  • Component 2 (C2): \(\mu_2 = 2.5\) (mean of \(\{2, 3\}\)), \(\sigma_2^2 = 1\), \(\pi_2 = 0.5\)

The professor noted: "It's not completely random. Python has its own ways of calculating the initial mean. Variance we assume as 1." This is akin to K-means initialization — picking sensible starting points based on domain knowledge.

16.5.3 Step 2 — E-step: Compute Responsibilities

For each point \(x \in \{0, 1, 2, 3\}\), compute the Gaussian likelihood under each component, then the responsibility \(r_{ik}\).

Gaussian PDF formula: \(\mathcal{N}(x \mid \mu, \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)\)

With \(\sigma^2 = 1\): \(\mathcal{N}(x \mid \mu, 1) = \frac{1}{\sqrt{2\pi}} \exp\left(-\frac{(x-\mu)^2}{2}\right)\)

For \(x = 0\):

\[ \begin{aligned} \mathcal{N}(0 \mid 0.5, 1) &= \frac{1}{\sqrt{2\pi}} e^{-(0-0.5)^2/2} = \frac{1}{2.5066} \cdot e^{-0.125} \approx 0.3521 \\ \mathcal{N}(0 \mid 2.5, 1) &= \frac{1}{\sqrt{2\pi}} e^{-(0-2.5)^2/2} = \frac{1}{2.5066} \cdot e^{-3.125} \approx 0.0175 \end{aligned} \] \[ r_{0,1} = \frac{0.5 \times 0.3521}{0.5 \times 0.3521 + 0.5 \times 0.0175} = \frac{0.1760}{0.1848} \approx 0.9526 \] \[ r_{0,2} = 1 - 0.9526 = 0.0474 \]

For \(x = 1\):

\[ \begin{aligned} \mathcal{N}(1 \mid 0.5, 1) &= \frac{1}{\sqrt{2\pi}} e^{-(0.5)^2/2} = 0.3521 \\ \mathcal{N}(1 \mid 2.5, 1) &= \frac{1}{\sqrt{2\pi}} e^{-(1.5)^2/2} = \frac{1}{2.5066} \cdot e^{-1.125} \approx 0.1295 \end{aligned} \] \[ r_{1,1} = \frac{0.3521}{0.3521 + 0.1295} \approx 0.7311, \quad r_{1,2} \approx 0.2689 \]

For \(x = 2\) (by symmetry with \(x = 1\)):

\[ r_{2,1} \approx 0.2689, \quad r_{2,2} \approx 0.7311 \]

For \(x = 3\) (by symmetry with \(x = 0\)):

\[ r_{3,1} \approx 0.0474, \quad r_{3,2} \approx 0.9526 \]

16.5.4 Step 3 — M-step: Update Parameters

Update \(\mu_1^{\text{new}}\) (weighted average):

\[ \mu_1^{\text{new}} = \frac{\sum_{i=1}^{4} r_{i,1} \cdot x_i}{\sum_{i=1}^{4} r_{i,1}} \]

Using the precise responsibilities:

\[ \begin{aligned} \mu_1^{\text{new}} &= \frac{0.9526(0) + 0.7311(1) + 0.2689(2) + 0.0474(3)}{0.9526 + 0.7311 + 0.2689 + 0.0474} \\ &= \frac{0 + 0.7311 + 0.5378 + 0.1422}{2.0000} = \frac{1.4111}{2.0000} = 0.7056 \end{aligned} \]

Using the lecture's approximate values (0.95, 0.80, 0.20, 0.05):

\[ \mu_1^{\text{new}} = \frac{0.95(0) + 0.80(1) + 0.20(2) + 0.05(3)}{0.95 + 0.80 + 0.20 + 0.05} = \frac{1.35}{2.00} = 0.675 \]

Update \(\mu_2^{\text{new}}\):

By symmetry, \(\mu_2^{\text{new}} = \frac{0.0474(0) + 0.2689(1) + 0.7311(2) + 0.9526(3)}{2.0} = \frac{0 + 0.2689 + 1.4622 + 2.8578}{2.0} = \frac{4.5889}{2.0} = 2.2944\)

With approximate values: \(\mu_2^{\text{new}} \approx 2.325\)

Update \(\sigma_1^{2,\text{new}}\) (weighted variance):

\[ \sigma_1^{2,\text{new}} = \frac{\sum_{i=1}^{4} r_{i,1} \cdot (x_i - \mu_1^{\text{new}})^2}{\sum_{i=1}^{4} r_{i,1}} \]

Using \(\mu_1^{\text{new}} = 0.7056\) and precise responsibilities:

\[ \begin{aligned} \sigma_1^{2,\text{new}} &= \frac{0.9526(0-0.7056)^2 + 0.7311(1-0.7056)^2 + 0.2689(2-0.7056)^2 + 0.0474(3-0.7056)^2}{2.0} \\ &= \frac{0.9526(0.4979) + 0.7311(0.0867) + 0.2689(1.6755) + 0.0474(5.2643)}{2.0} \\ &= \frac{0.4743 + 0.0634 + 0.4505 + 0.2495}{2.0} = \frac{1.2377}{2.0} = 0.6189 \end{aligned} \]

The variance has shrunk from 1.0 to ~0.62 — the cluster is tightening around its data.

Update mixing coefficients:

\[ \pi_1^{\text{new}} = \frac{1}{4} \sum_{i=1}^{4} r_{i,1} = \frac{2.0}{4} = 0.5, \quad \pi_2^{\text{new}} = 0.5 \]

The mixing coefficients stay at 0.5 because the responsibilities are symmetric.

16.5.5 Step 4 — Repeat Until Convergence

The E-step and M-step are repeated. In this example, after one iteration the most-likely cluster assignments are already correct (0,1 → C1; 2,3 → C2). Running the E-step again with the updated parameters produces the same hard assignments, so the algorithm converges.

For larger datasets with more overlap, multiple iterations are needed. In general, stop when:

  • The log-likelihood change \(|\mathcal{L}^{(t+1)} - \mathcal{L}^{(t)}| < \varepsilon\) (e.g., \(10^{-3}\)), or
  • Parameter changes are below threshold, or
  • Cluster assignments stop changing.

The mixing coefficients stayed at 0.5 each for this symmetric example, but in asymmetric real datasets, \(\pi_k\) values shift to reflect the relative sizes of the discovered clusters.

After one EM iteration, both Gaussian means moved toward their natural clusters (\(\mu_1\) shifted right, \(\mu_2\) shifted left), and both variances shrank (the clusters became tighter). The algorithm stops when these movements become negligible. Final answer: after convergence, \(\mu_1 \approx 0.5\)–\(1.0\) (centered on \(\{0,1\}\)), \(\mu_2 \approx 2.0\)–\(2.5\) (centered on \(\{2,3\}\)), \(\sigma_1^2 \approx \sigma_2^2 \approx 0.25\) (quarter of initial variance), \(\pi_1 = \pi_2 = 0.5\).

16.6 GMM — Practical Considerations

16.6.1 Choosing the Number of Components \(K\)

"How many clusters are in my data?" is one of the hardest questions in unsupervised learning. GMM doesn't answer it — you must choose \(K\). These are the tools to make that choice.

Methods shared with K-means:

  1. Elbow method — Run GMM for \(K = 1, 2, 3, \ldots\) and plot the log-likelihood (or BIC/AIC). The curve typically rises sharply at first, then bends like an elbow. Pick the \(K\) at the bend — after that point, adding more components gives diminishing returns.
  2. Silhouette analysis — For each point, compute the silhouette score: \((b - a) / \max(a, b)\), where \(a\) is the mean distance to points in the same cluster, and \(b\) is the mean distance to points in the nearest other cluster. Values range from \(-1\) (wrong cluster) to \(+1\) (well-clustered). Average across all points and pick the \(K\) that maximizes the average silhouette.
  3. Cross-validation — Split the data, train GMM on folds, evaluate log-likelihood on held-out data. Pick the \(K\) that gives the best held-out likelihood.

Methods specific to GMM:

4. Bayesian Information Criterion (BIC): \[ \text{BIC} = -2 \log L + K_{\text{params}} \cdot \ln(n) \] 5. Akaike Information Criterion (AIC): \[ \text{AIC} = -2 \log L + 2 K_{\text{params}} \] Where:
  • \(L\) — the maximized likelihood of the model (how well it fits). Larger \(L\) = better fit, so \(-2\log L\) is smaller for better fit.
  • \(K_{\text{params}}\) — the total number of free parameters. For GMM with \(K\) components in \(d\) dimensions: means (\(Kd\)), covariances (\(Kd(d+1)/2\) for full covariance), and mixing coefficients (\(K-1\), since they sum to 1).
  • \(n\) — number of data points.
  • Lower BIC or AIC is better.

The difference: BIC penalizes complexity more heavily (\(\ln(n)\) vs. 2), so it favors simpler models for large \(n\). AIC tends to select slightly more complex models.

Procedure: Run GMM for \(K = 1, 2, 3, 4, 5, \ldots\). For each \(K\), record the BIC and AIC scores. Plot them. Pick the \(K\) that minimizes the score. The scores come directly from the GMM fitting output — Python's sklearn.mixture.GaussianMixture provides both .bic() and .aic() methods.

16.6.2 Initialization Strategies

Pitfall: Random initialization can trap EM in poor local optima. Good initialization matters — it can mean the difference between finding meaningful clusters and getting nonsense.
  1. Random initialization — Pick random \(\mu_k\) and \(\sigma_k^2\). Simple but unreliable. Run multiple times with different seeds and keep the best result (highest log-likelihood).
  2. Hierarchical splitting — Start with \(K = 1\) (a single Gaussian over all data). Find the component with the largest variance and split it into two. Repeat until you reach the desired \(K\). Analogous to choosing the two farthest centroids in K-means initialization.
  3. K-means first, then GMM (recommended) — This is what scikit-learn does by default:
    • Run K-means with the desired \(K\).
    • Set initial \(\boldsymbol{\mu}_k\) = centroid of K-means cluster \(k\).
    • Set initial \(\boldsymbol{\Sigma}_k\) = sample covariance of points in cluster \(k\).
    • Set initial \(\pi_k\) = (points in cluster \(k\)) / (total points).
    K-means is fast and gives sensible starting positions. EM then refines from there, adding soft assignments and elliptical shapes.

16.6.3 Convergence Criteria

All three are equivalent in practice — they detect when the model has stopped improving:

  1. Parameter change below threshold — Stop when \(|\mu_k^{(t+1)} - \mu_k^{(t)}| < \varepsilon\), \(|\sigma_k^{2,(t+1)} - \sigma_k^{2,(t)}| < \varepsilon\), and \(|\pi_k^{(t+1)} - \pi_k^{(t)}| < \varepsilon\) for all \(k\).
  2. Log-likelihood change below threshold — The most principled approach. Stop when: \[ |\mathcal{L}^{(t+1)} - \mathcal{L}^{(t)}| < \varepsilon \] where \(\mathcal{L} = \sum_{i=1}^{n} \ln p(x_i)\) is the log-likelihood. Typical \(\varepsilon = 10^{-3}\).
  3. Assignment stability — Stop when no point changes its most-likely cluster between iterations (or when fewer than a tolerance fraction change).
Choosing \(K\) is an art: use BIC/AIC + elbow method. Initializing well is a science: use K-means first. Knowing when to stop is simple: watch the log-likelihood plateau. With these three practical decisions made, GMM is a robust and widely applicable clustering tool. 16.7 Support Vector Machines — Core Concept

If I show you three lines separating two groups of points and ask which one you'd pick — without knowing any machine learning — you'd choose the one in the middle that gives both groups breathing room. That instinct is the Support Vector Machine. "That's the end of SVM," as the professor put it.

16.7.1 The Classification Problem

Consider predicting whether a student gets admission into their top-choice IIT. Two features matter: CGPA and JEE score. Plot each student as a point on a 2D graph:

  • Blue triangles ▲ = students who got in → label \(+1\)
  • Red circles ● = students who did not → label \(-1\)

The task: draw a line that separates these two classes. In higher dimensions, this becomes a hyperplane.

Visual intuition: The x-axis is CGPA, the y-axis is JEE score. Blue points cluster in the top-right (high CGPA, high JEE). Red points cluster in the bottom-left. The separator is a straight line cutting diagonally between them.

16.7.2 Which Line Is Best?

The professor showed three candidate lines:

  • L₁: Separates the data but is dangerously close to the red points. A new red observation slightly different from the training data could easily fall on the wrong side. No safety margin.
  • L₃: Separates the data but is dangerously close to the blue points. Same problem — no breathing room on the blue side.
  • L₂: Sits squarely in the middle, giving breathing room to both classes. Even if new observations vary slightly from the training data, they are likely to stay on the correct side.
"If I ask you — you don't know machine learning — which among these three lines will you be choosing to differentiate these two classes? You would pick L₂ because it gives breathing space. That is SVM."

16.7.3 Decision Boundary, Margin, and Support Vectors

Three key geometric concepts define the SVM:

Decision boundary (the dashed middle line):

\[ \mathbf{w} \cdot \mathbf{x} - b = 0 \] At this line, the prediction is 50-50 — we cannot decide the class. Points exactly on this line are equally likely to be either class.

Margin — The distance from the decision boundary to the nearest data point of each class. The total gap between the two outer margin lines is \(2 / \|\mathbf{w}\|\). The SVM's goal is to make this as wide as possible.

Support vectors — The data points that lie exactly on the margin boundaries (or are closest to the decision boundary). These are the hardest points to classify — the ones that constrain how wide the margin can be. They are the only points that matter for determining \(\mathbf{w}\) and \(b\).

The "namaste" analogy: The professor gave a vivid physical metaphor:

"When you're doing namaste, how much can you move your hands apart so that you don't touch the people on both sides? I want to move my hands as far as possible. When you touch somebody on one side, that much only we will take on the other side also — that is the maximum."

Your hands are the margin lines. The people on either side are the support vectors. You spread your hands until they touch the nearest person on each side. That equal distance on both sides defines the maximum margin. The decision boundary runs exactly halfway between your hands.

Critical property of support vectors: If you move any data point that is NOT a support vector, the decision boundary and margin do not change at all. If you move a support vector, the boundary shifts. That is why they are called "support" vectors — they literally support the margin. All other points are irrelevant once the SVM is trained. This sparsity is what makes SVMs efficient: after training, you can discard all non-support-vector data points.

16.7.4 SVM as an Optimization Problem

SVM is fundamentally an optimization (maximization) problem:
  • Goal: Maximize the margin = \(2 / \|\mathbf{w}\|\).
  • Constraint: Every training point must lie on or outside its respective margin line (for hard-margin SVM).

In different dimensions, the separator has different names:

  • 2D: find the best line.
  • 3D: find the best plane.
  • 4D and higher: find the best hyperplane.

The math treats all cases uniformly — even a line is a "hyperplane" in the formalism: only the first weight term is non-zero, and the rest vanish. The professor noted: "In literature, even a line is called a hyperplane because the hyperplane equation is used."

SVM is a supervised classification algorithm. Unlike GMM (unsupervised clustering), SVM requires labeled training data: you must know which points are \(+1\) and which are \(-1\).

16.7.5 Hard Margin vs. Soft Margin

Scope: Hard-margin SVM assumes the data is linearly separable — that there exists a hyperplane perfectly separating the two classes. In real data, this assumption almost never holds.

Hard margin SVM: No misclassifications allowed. Every training point must be on the correct side of (or exactly on) its margin line. Problem: if there is an outlier — say, a red point deep in blue territory — SVM is forced to draw the boundary near that outlier, producing a terrible classifier.

The professor's example: "Consider some student who got a very high JEE score but due to some issue (say CGPA problem, or some malpractice identified later), even though the student seems like a top candidate, they were not selected. The data point sits in blue territory but is actually red. SVM will draw the boundary near that outlier, creating a wrong boundary."

Soft margin SVM: Allows some misclassifications. The algorithm tolerates a few points on the wrong side of the margin, paying a penalty proportional to the violation. This makes the model more generalizable and less sensitive to outliers. Soft margin SVM (with slack variables \(\xi_n\)) is covered in the next class and is what is used in virtually all real-world applications.

SVM is the art of finding the widest street between two classes. The street's center line is the decision boundary, its edges are defined by the support vectors, and its width is the margin. Everything else — the primal optimization, the dual formulation, the Lagrangian — is machinery to compute this geometrically intuitive idea efficiently, especially in high dimensions.

16.8 SVM — Mathematical Formulation

16.8.1 Setup and Notation

We have \(n\) data points. For each point \(i\):
  • \(\mathbf{x}_i \in \mathbb{R}^d\) — a vector of \(d\) features (e.g., CGPA and JEE score, so \(d = 2\)).
  • \(y_i \in \{+1, -1\}\) — the class label.
    • \(y_i = +1\): positive class (got admission, blue triangle ▲)
    • \(y_i = -1\): negative class (did not get admission, red circle ●)
The SVM learns a function \(f(\mathbf{x}) = \mathbf{w} \cdot \mathbf{x} - b\) from the training data. The sign of \(f(\mathbf{x})\) gives the predicted class:
  • If \(f(\mathbf{x}) \geq 0\) → predict \(+1\)
  • If \(f(\mathbf{x}) < 0\) → predict \(-1\)

16.8.2 Hyperplane Equations

Three parallel hyperplanes define the SVM:

Decision boundary (dashed middle line):

\[ \mathbf{w} \cdot \mathbf{x} - b = 0 \quad \text{or} \quad \mathbf{w}^\top \mathbf{x} - b = 0 \]

Right margin line (positive side, prediction = \(+1\)):

\[ \mathbf{w} \cdot \mathbf{x} - b = 1 \]

Left margin line (negative side, prediction = \(-1\)):

\[ \mathbf{w} \cdot \mathbf{x} - b = -1 \] Where:
  • \(\mathbf{w}\) — the weight vector. Like the slope coefficients in a line equation. \(\mathbf{w} \in \mathbb{R}^d\).
  • \(b\) — the bias (intercept). A scalar. Shifts the hyperplane away from the origin.
  • \(\mathbf{x}\) — a feature vector.

Any point with \(\mathbf{w} \cdot \mathbf{x} - b \geq 1\) is classified \(+1\). Any point with \(\mathbf{w} \cdot \mathbf{x} - b \leq -1\) is classified \(-1\). Points in between (\(-1 < \mathbf{w} \cdot \mathbf{x} - b < 1\)) lie inside the margin.

What about 2D? For a line in 2D, the equation is \(w_1 x_1 + w_2 x_2 - b = 0\). This is exactly the hyperplane equation with \(d = 2\). The professor emphasized: "Even though it is lower dimension, they use the hyperplane equation itself."

16.8.3 The Normal Vector

From vector algebra: for a hyperplane \(\mathbf{w} \cdot \mathbf{x} - b = 0\), the weight vector \(\mathbf{w}\) is perpendicular (normal) to the hyperplane.

Why this matters: To measure the margin, we need the shortest distance from a point to the hyperplane. The shortest path is always along the normal direction — the direction of \(\mathbf{w}\). This is why the margin width ends up being \(2 / \|\mathbf{w}\|\).

16.8.4 Deriving the Margin Size

Step-by-step derivation of the margin width:

Start on the decision boundary: \(\mathbf{w} \cdot \mathbf{x} - b = 0\). Walk \(K\) units in the direction of \(\mathbf{w}\) (perpendicular to the boundary) until you hit the \(+1\) line \(\mathbf{w} \cdot \mathbf{x} - b = 1\).

The unit vector in the direction of \(\mathbf{w}\) is \(\frac{\mathbf{w}}{\|\mathbf{w}\|}\). So your new position is:

\[ \mathbf{x}_{\text{new}} = \mathbf{x} + K \cdot \frac{\mathbf{w}}{\|\mathbf{w}\|} \]

Plug this into the \(+1\) line equation:

\[ \mathbf{w} \cdot \left(\mathbf{x} + K \frac{\mathbf{w}}{\|\mathbf{w}\|}\right) - b = 1 \]

Distribute the dot product:

\[ \mathbf{w} \cdot \mathbf{x} + K \frac{\mathbf{w} \cdot \mathbf{w}}{\|\mathbf{w}\|} - b = 1 \]

Since you started on the decision boundary, \(\mathbf{w} \cdot \mathbf{x} - b = 0\). Substitute:

\[ 0 + K \frac{\mathbf{w} \cdot \mathbf{w}}{\|\mathbf{w}\|} = 1 \]

Now \(\mathbf{w} \cdot \mathbf{w} = \|\mathbf{w}\|^2\) (definition of the squared norm):

\[ K \frac{\|\mathbf{w}\|^2}{\|\mathbf{w}\|} = K \|\mathbf{w}\| = 1 \] \[ \boxed{K = \frac{1}{\|\mathbf{w}\|}} \]

So the distance from the decision boundary to one margin line is \(1 / \|\mathbf{w}\|\). The total margin (gap between the \(-1\) and \(+1\) lines) is:

\[ \boxed{\text{Margin} = 2K = \frac{2}{\|\mathbf{w}\|}} \]

Sense check: As \(\|\mathbf{w}\|\) gets smaller, the margin gets larger. If \(\|\mathbf{w}\| \to 0\), the margin \(\to \infty\) (but then the hyperplane would classify everything as one class — the constraints prevent this). ✓

16.8.5 The Optimization Problem (Primal Form)

Goal: Maximize the margin = \(2 / \|\mathbf{w}\|\).

Maximizing \(2 / \|\mathbf{w}\|\) is equivalent to minimizing \(\|\mathbf{w}\|\). For mathematical convenience, we minimize \(\frac{1}{2}\|\mathbf{w}\|^2\) instead. The factor \(1/2\) makes the derivative clean: \(\frac{\partial}{\partial \mathbf{w}} \frac{1}{2}\|\mathbf{w}\|^2 = \mathbf{w}\).

\[ \min_{\mathbf{w}, b} \frac{1}{2} \|\mathbf{w}\|^2 \]

Subject to the constraint that every point is correctly classified and lies on or outside its margin:

\[ y_i (\mathbf{w} \cdot \mathbf{x}_i - b) \geq 1 \quad \text{for all } i = 1, 2, \ldots, n \]

Why does one inequality cover both classes?

  • For \(y_i = +1\): We need \(\mathbf{w} \cdot \mathbf{x}_i - b \geq 1\). Multiply by \(y_i = +1\): \(y_i(\mathbf{w} \cdot \mathbf{x}_i - b) \geq 1\). ✓
  • For \(y_i = -1\): We need \(\mathbf{w} \cdot \mathbf{x}_i - b \leq -1\). Multiply both sides by \(-1\) (flipping the inequality): \(-(\mathbf{w} \cdot \mathbf{x}_i - b) \geq 1\). Since \(y_i = -1\): \(y_i(\mathbf{w} \cdot \mathbf{x}_i - b) \geq 1\). ✓

Both cases reduce to the same inequality. This elegant trick is what makes the SVM formulation so compact.

The professor: "From where did the ½ come? Nowhere. It is just a mathematical convenience so that when we take the gradient later it will be easier. You remember in linear regression also we used to add ½ so that the derivative becomes easy."

This is a quadratic programming problem: minimize a quadratic objective subject to linear inequality constraints. For this class of problems, any local minimum is also a global minimum — a crucial property that makes SVM optimization reliable.

16.9 From Primal to Dual — The Lagrangian Approach

The primal SVM problem optimizes over \(\mathbf{w}\) (a \(d\)-dimensional vector). But what if \(d\) is enormous — say, every pixel in an image is a feature? The dual reformulation pivots from optimizing over \(d\) variables to optimizing over \(n\) variables, where \(n\) is the number of data points. When \(n \ll d\) (few images, many pixels), this is a massive computational win.

16.9.1 Why Convert to a Dual Problem?

In the primal problem, we minimize \(\frac{1}{2}\|\mathbf{w}\|^2\) over \(\mathbf{w} \in \mathbb{R}^d\). The computation involves dot products \(\mathbf{w} \cdot \mathbf{x}_i\) for every data point. When \(d\) is large — think image data with 10,000+ pixels per image but only a few hundred images — this is expensive.

The dual formulation transforms the problem so that:

  • We optimize over \(n\) Lagrangian multipliers \(\alpha_i\) instead of the \(d\)-dimensional \(\mathbf{w}\).
  • Only the \(\alpha_i\) for support vectors are non-zero. All other \(\alpha_i = 0\).
  • The data appears only as dot products between pairs of points (\(\mathbf{x}_i^\top \mathbf{x}_j\)), not between weights and features.
  • When \(n \ll d\), the dual is far cheaper to solve.

The professor's own words: "In large dimension data, the number of records are much smaller than the number of columns. So this calculation will be reduced a lot. That's the reason we are doing all of this gimmick."

Note on dimensions: When \(d\) is small compared to \(n\), the primal form is actually more efficient. The dual form is specifically designed for the \(n \ll d\) regime (e.g., image classification, text classification with bag-of-words). The professor focused on the dual because it also sets up the kernel trick (next lecture), where the dimension can be infinite.

16.9.2 Lagrangian Function

For each constraint \(y_i(\mathbf{w}^\top \mathbf{x}_i - b) \geq 1\), we introduce a Lagrangian multiplier \(\alpha_i \geq 0\). The Lagrangian function is: \[ \mathcal{L}(\mathbf{w}, b, \boldsymbol{\alpha}) = \frac{1}{2} \|\mathbf{w}\|^2 - \sum_{i=1}^{n} \alpha_i \left[ y_i (\mathbf{w}^\top \mathbf{x}_i - b) - 1 \right] \] This is the standard SVM Lagrangian form (Bishop §7.1, equation 7.7). The minus sign is by convention: we minimize with respect to \(\mathbf{w}\) and \(b\) and maximize with respect to \(\boldsymbol{\alpha}\).

16.9.3 KKT Conditions and Stationarity

The Karush-Kuhn-Tucker (KKT) conditions are necessary conditions for optimality in constrained optimization. The professor noted they are covered in the Mathematical Foundations for ML course. The key condition for the dual derivation is stationarity: set the partial derivatives of the Lagrangian to zero.

Derivative with respect to \(\mathbf{w}\): \[ \frac{\partial \mathcal{L}}{\partial \mathbf{w}} = \mathbf{w} - \sum_{i=1}^{n} \alpha_i y_i \mathbf{x}_i = 0 \] \[ \boxed{\mathbf{w} = \sum_{i=1}^{n} \alpha_i y_i \mathbf{x}_i} \] This is a beautiful result: the optimal weight vector \(\mathbf{w}\) is a linear combination of the training data points, each weighted by \(\alpha_i y_i\). Only points with \(\alpha_i > 0\) contribute — those are the support vectors.

Derivative with respect to \(b\):

\[ \frac{\partial \mathcal{L}}{\partial b} = -\sum_{i=1}^{n} \alpha_i y_i (-1) = \sum_{i=1}^{n} \alpha_i y_i = 0 \]

Wait — let's compute carefully. The term inside the sum is \(-\alpha_i[y_i(\mathbf{w}^\top\mathbf{x}_i - b) - 1] = -\alpha_i y_i \mathbf{w}^\top\mathbf{x}_i + \alpha_i y_i b + \alpha_i\). Taking derivative with respect to \(b\): \(\frac{\partial}{\partial b}(\alpha_i y_i b) = \alpha_i y_i\). So:

\[ \frac{\partial \mathcal{L}}{\partial b} = \sum_{i=1}^{n} \alpha_i y_i = 0 \] \[ \boxed{\sum_{i=1}^{n} \alpha_i y_i = 0} \] This is a constraint on the \(\alpha_i\) values: the weighted sum of labels must be zero.

16.9.4 The Dual Problem

Complete derivation from primal to dual:

Substitute \(\mathbf{w} = \sum_{j=1}^{n} \alpha_j y_j \mathbf{x}_j\) and the constraints into the Lagrangian:

\[ \begin{aligned} \mathcal{L} &= \frac{1}{2}\|\mathbf{w}\|^2 - \sum_{i=1}^{n} \alpha_i \left[ y_i (\mathbf{w}^\top \mathbf{x}_i - b) - 1 \right] \\[4pt] &= \frac{1}{2} \left(\sum_{i} \alpha_i y_i \mathbf{x}_i\right)^\top \left(\sum_{j} \alpha_j y_j \mathbf{x}_j\right) - \sum_{i} \alpha_i y_i \mathbf{w}^\top \mathbf{x}_i + \sum_{i} \alpha_i y_i b + \sum_{i} \alpha_i \\[4pt] &= \frac{1}{2} \sum_{i} \sum_{j} \alpha_i \alpha_j y_i y_j (\mathbf{x}_i^\top \mathbf{x}_j) - \sum_{i} \alpha_i y_i \left(\sum_{j} \alpha_j y_j \mathbf{x}_j\right)^\top \mathbf{x}_i + b\underbrace{\sum_{i} \alpha_i y_i}_{=0} + \sum_{i} \alpha_i \\[4pt] &= \frac{1}{2} \sum_{i} \sum_{j} \alpha_i \alpha_j y_i y_j (\mathbf{x}_i^\top \mathbf{x}_j) - \sum_{i} \sum_{j} \alpha_i \alpha_j y_i y_j (\mathbf{x}_j^\top \mathbf{x}_i) + \sum_{i} \alpha_i \\[4pt] &= -\frac{1}{2} \sum_{i=1}^{n} \sum_{j=1}^{n} \alpha_i \alpha_j y_i y_j (\mathbf{x}_i^\top \mathbf{x}_j) + \sum_{i=1}^{n} \alpha_i \end{aligned} \]

The bias term vanishes because \(\sum_i \alpha_i y_i = 0\). The two double sums combine (they're the same sum since \(\mathbf{x}_i^\top \mathbf{x}_j = \mathbf{x}_j^\top \mathbf{x}_i\)), giving \(\frac{1}{2} - 1 = -\frac{1}{2}\).

The dual maximization problem:

\[ \boxed{\max_{\boldsymbol{\alpha} \geq 0} \sum_{i=1}^{n} \alpha_i - \frac{1}{2} \sum_{i=1}^{n} \sum_{j=1}^{n} \alpha_i \alpha_j y_i y_j (\mathbf{x}_i^\top \mathbf{x}_j)} \] Subject to: \(\sum_{i=1}^{n} \alpha_i y_i = 0\) and \(\alpha_i \geq 0\) for all \(i\).

Equivalently, as a minimization (negate the objective, which is what most solvers use):

\[ \min_{\boldsymbol{\alpha} \geq 0} \frac{1}{2} \sum_{i=1}^{n} \sum_{j=1}^{n} \alpha_i \alpha_j y_i y_j (\mathbf{x}_i^\top \mathbf{x}_j) - \sum_{i=1}^{n} \alpha_i \] This is the standard dual form from Bishop §7.1 (equation 7.10). The primal and dual are equivalent — solving one gives the solution to the other via \(\mathbf{w} = \sum_i \alpha_i y_i \mathbf{x}_i\).

16.9.5 Why the Dual Is More Efficient

In the dual, data appears only as dot products \(\mathbf{x}_i^\top \mathbf{x}_j\). The \(\alpha_i\) are non-zero only for support vectors (a consequence of the KKT complementary slackness condition: \(\alpha_i [y_i(\mathbf{w}^\top \mathbf{x}_i - b) - 1] = 0\)).

So the double sum \(\sum_i \sum_j\) is effectively only over support vectors — a small fraction of the training data. This makes the dual dramatically more efficient when \(n \ll d\).

KKT complementary slackness (the reason for sparsity): For every data point, either \(\alpha_i = 0\) (point is irrelevant — not a support vector) or \(y_i(\mathbf{w}^\top \mathbf{x}_i - b) = 1\) (point lies exactly on its margin boundary — it IS a support vector). Most points have \(\alpha_i = 0\) and can be discarded after training.

16.9.6 The Classification Function

Once the \(\alpha_i\) are found, classification of a new point \(\mathbf{x}\) uses: \[ \boxed{f(\mathbf{x}) = \sum_{i=1}^{n} \alpha_i y_i (\mathbf{x}_i^\top \mathbf{x}) + b} \]
  • If \(f(\mathbf{x}) \geq 0\) → classify as \(+1\)
  • If \(f(\mathbf{x}) < 0\) → classify as \(-1\)

The weight vector is recovered as \(\mathbf{w} = \sum_{i=1}^{n} \alpha_i y_i \mathbf{x}_i\).

Computing \(b\) (the bias): For any support vector \(\mathbf{x}_s\) (a point with \(\alpha_s > 0\)), we know \(y_s(\mathbf{w}^\top \mathbf{x}_s - b) = 1\). Solving for \(b\):

\[ y_s\left(\sum_{j=1}^{n} \alpha_j y_j (\mathbf{x}_j^\top \mathbf{x}_s) - b\right) = 1 \]

Since \(y_s^2 = 1\), multiply through by \(y_s\):

\[ b = \sum_{j=1}^{n} \alpha_j y_j (\mathbf{x}_j^\top \mathbf{x}_s) - y_s \]

For numerical stability, average over all support vectors \(S\) (Bishop §7.1, equation 7.18):

\[ b = \frac{1}{|S|} \sum_{s \in S} \left( y_s - \sum_{j \in S} \alpha_j y_j (\mathbf{x}_j^\top \mathbf{x}_s) \right) \]
For exam problem-solving, you need only three equations:
  1. Classification: \(f(\mathbf{x}) = \sum_i \alpha_i y_i (\mathbf{x}_i^\top \mathbf{x}) + b\)
  2. Weight vector: \(\mathbf{w} = \sum_i \alpha_i y_i \mathbf{x}_i\)
  3. Bias: \(b\) computed from any support vector as above.
The Lagrangian and KKT derivations are for conceptual understanding — the professor stated explicitly: "Derivations you can take from the slide. Nobody may ask, but ML maybe will not ask."

16.10 SVM — Worked Example

This is the canonical exam-style SVM problem. The professor stated: "Just please study solving system of linear equations. Otherwise you will not be able to solve this here." Work through every step — the math is straightforward but you need to be systematic.

16.10.1 Problem Setup

Three data points, each with features augmented by a bias column of 1:

PointFeatures (with bias)Label \(y\)
\(\mathbf{x}_1\)\((0, 1, 1)\)\(-1\)
\(\mathbf{x}_2\)\((-1, 3, 1)\)\(+1\)
\(\mathbf{x}_3\)\((1, 3, 1)\)\(+1\)

The third component "1" is the bias term added manually — the same technique used in linear regression when adding a column of ones for the intercept. This absorbs \(b\) into the weight vector: the third component of \(\mathbf{w}\) will be \(-b\).

Visual intuition: Plot these in 2D (ignoring the bias column). \(\mathbf{x}_1 = (0, 1)\) is the lone negative point at the bottom. \(\mathbf{x}_2 = (-1, 3)\) and \(\mathbf{x}_3 = (1, 3)\) are the two positive points at the top, symmetrically placed. The decision boundary should be a horizontal line somewhere between \(y = 1\) and \(y = 3\).

16.10.2 Step 1 — Write the System of Linear Equations

For support vectors (all three points will turn out to be support vectors), the classification condition is:

\[ \sum_{j=1}^{3} \alpha_j y_j (\mathbf{x}_j^\top \mathbf{x}_i) = y_i \]

For \(i = 1\) (\(y_1 = -1\)):

\[ \alpha_1(-1)(\mathbf{x}_1^\top \mathbf{x}_1) + \alpha_2(+1)(\mathbf{x}_2^\top \mathbf{x}_1) + \alpha_3(+1)(\mathbf{x}_3^\top \mathbf{x}_1) = -1 \]

Compute the dot products:

  • \(\mathbf{x}_1^\top \mathbf{x}_1 = 0^2 + 1^2 + 1^2 = 2\) → \(\alpha_1(-1)(2) = -2\alpha_1\)
  • \(\mathbf{x}_2^\top \mathbf{x}_1 = (-1)(0) + 3(1) + 1(1) = 4\) → \(\alpha_2(+1)(4) = 4\alpha_2\)
  • \(\mathbf{x}_3^\top \mathbf{x}_1 = 1(0) + 3(1) + 1(1) = 4\) → \(\alpha_3(+1)(4) = 4\alpha_3\)
\[ \boxed{-2\alpha_1 + 4\alpha_2 + 4\alpha_3 = -1} \quad \text{(Eq 1)} \]

For \(i = 2\) (\(y_2 = +1\)):

  • \(\mathbf{x}_1^\top \mathbf{x}_2 = 0(-1) + 1(3) + 1(1) = 4\) → \(\alpha_1(-1)(4) = -4\alpha_1\)
  • \(\mathbf{x}_2^\top \mathbf{x}_2 = (-1)^2 + 3^2 + 1^2 = 1 + 9 + 1 = 11\) → \(\alpha_2(+1)(11) = 11\alpha_2\)
  • \(\mathbf{x}_3^\top \mathbf{x}_2 = 1(-1) + 3(3) + 1(1) = -1 + 9 + 1 = 9\) → \(\alpha_3(+1)(9) = 9\alpha_3\)
\[ \boxed{-4\alpha_1 + 11\alpha_2 + 9\alpha_3 = 1} \quad \text{(Eq 2)} \]

For \(i = 3\) (\(y_3 = +1\)):

  • \(\mathbf{x}_1^\top \mathbf{x}_3 = 0(1) + 1(3) + 1(1) = 4\) → \(\alpha_1(-1)(4) = -4\alpha_1\)
  • \(\mathbf{x}_2^\top \mathbf{x}_3 = (-1)(1) + 3(3) + 1(1) = -1 + 9 + 1 = 9\) → \(\alpha_2(+1)(9) = 9\alpha_2\)
  • \(\mathbf{x}_3^\top \mathbf{x}_3 = 1^2 + 3^2 + 1^2 = 1 + 9 + 1 = 11\) → \(\alpha_3(+1)(11) = 11\alpha_3\)
\[ \boxed{-4\alpha_1 + 9\alpha_2 + 11\alpha_3 = 1} \quad \text{(Eq 3)} \]

16.10.3 Step 2 — Solve the System of Linear Equations

\[ \begin{cases} -2\alpha_1 + 4\alpha_2 + 4\alpha_3 = -1 & \text{(Eq 1)} \\[4pt] -4\alpha_1 + 11\alpha_2 + 9\alpha_3 = 1 & \text{(Eq 2)} \\[4pt] -4\alpha_1 + 9\alpha_2 + 11\alpha_3 = 1 & \text{(Eq 3)} \end{cases} \]

Subtract Eq 3 from Eq 2:

\[ (-4\alpha_1 + 11\alpha_2 + 9\alpha_3) - (-4\alpha_1 + 9\alpha_2 + 11\alpha_3) = 1 - 1 \] \[ 2\alpha_2 - 2\alpha_3 = 0 \quad \Rightarrow \quad \boxed{\alpha_2 = \alpha_3} \]

Let \(\alpha_2 = \alpha_3 = t\). Substitute into Eq 1:

\[ -2\alpha_1 + 4t + 4t = -1 \quad \Rightarrow \quad -2\alpha_1 + 8t = -1 \quad \Rightarrow \quad \alpha_1 = 4t + 0.5 \]

Substitute into Eq 2:

\[ -4(4t + 0.5) + 11t + 9t = 1 \] \[ -16t - 2 + 20t = 1 \] \[ 4t - 2 = 1 \quad \Rightarrow \quad 4t = 3 \quad \Rightarrow \quad \boxed{t = 0.75} \]

Therefore:

\[ \boxed{\alpha_2 = \alpha_3 = 0.75}, \quad \boxed{\alpha_1 = 4(0.75) + 0.5 = 3.5} \]

All three \(\alpha_i > 0\) → all three points are support vectors.

16.10.4 Step 3 — Compute \(\mathbf{w}\) and \(b\)

\[ \begin{aligned} \mathbf{w} &= \sum_{i=1}^{3} \alpha_i y_i \mathbf{x}_i \\ &= 3.5(-1)(0, 1, 1) + 0.75(+1)(-1, 3, 1) + 0.75(+1)(1, 3, 1) \\ &= (-3.5)(0, 1, 1) + 0.75(-1, 3, 1) + 0.75(1, 3, 1) \\ &= (0, -3.5, -3.5) + (-0.75, 2.25, 0.75) + (0.75, 2.25, 0.75) \\ &= \boxed{(0, 1, -2)} \end{aligned} \]

So \(\mathbf{w} = (w_1, w_2, w_3) = (0, 1, -2)\). The third component \(w_3 = -2\) is the negative of the bias: \(b = -w_3 = 2\).

16.10.5 Step 4 — Write the Decision Boundary

The decision boundary: \(\mathbf{w} \cdot \mathbf{x} = 0\).

\[ 0 \cdot x_1 + 1 \cdot x_2 + (-2) \cdot 1 = 0 \quad \Rightarrow \quad x_2 - 2 = 0 \quad \Rightarrow \quad \boxed{x_2 = 2} \]

The decision boundary is the horizontal line \(y = 2\).

The margin lines:

  • Right side (\(+1\)): \(\mathbf{w} \cdot \mathbf{x} = 1\) → \(x_2 - 2 = 1\) → \(x_2 = 3\)
  • Left side (\(-1\)): \(\mathbf{w} \cdot \mathbf{x} = -1\) → \(x_2 - 2 = -1\) → \(x_2 = 1\)

Verification — check that support vectors lie on margin lines:

  • \(\mathbf{x}_2 = (-1, 3, 1)\): \(1 \cdot 3 - 2 = 1\) ✓ (on \(+1\) margin)
  • \(\mathbf{x}_3 = (1, 3, 1)\): \(1 \cdot 3 - 2 = 1\) ✓ (on \(+1\) margin)
  • \(\mathbf{x}_1 = (0, 1, 1)\): \(1 \cdot 1 - 2 = -1\) ✓ (on \(-1\) margin)

Margin width: \(\|\mathbf{w}\| = \sqrt{0^2 + 1^2 + (-2)^2} = \sqrt{5}\). The effective margin in the 2D projection is the distance between the margin lines: \(3 - 1 = 2\).

16.10.6 Interpretation

Classification rule:
  • Any point with \(x_2 \geq 2\) (on or above \(y = 2\)) → class \(+1\)
  • Any point with \(x_2 < 2\) (below \(y = 2\)) → class \(-1\)
The decision boundary \(y = 2\) sits exactly halfway between the negative point at \(y = 1\) and the positive points at \(y = 3\). This is the maximum-margin solution: the margin of 1 unit on each side is the largest possible given these three points.

Sense check: The two positive points \(\mathbf{x}_2\) and \(\mathbf{x}_3\) are at the same \(y = 3\) height, symmetrically placed at \(x = -1\) and \(x = +1\). The single negative point \(\mathbf{x}_1\) is at \(y = 1\), \(x = 0\). The maximum-margin line should indeed be horizontal at \(y = 2\) — the midpoint. The \(x\)-coordinate doesn't matter because both positive points share the same \(y\)-value, making the problem effectively 1D in the \(y\) direction. ✓

The worked example shows the full pipeline: set up the \(\alpha\)-equations from dot products → solve the linear system → compute \(\mathbf{w} = \sum \alpha_i y_i \mathbf{x}_i\) → extract \(b\) from \(\mathbf{w}\)'s bias component → write the decision boundary. For the exam, the professor emphasized: "These three equations — \(f(\mathbf{x})\) (classification function), \(\mathbf{w}\) equation, and \(b\) equation — you just use those three equations for problem solving."

16.11 Student Questions and Answers

The following questions capture distinct confusion points raised during the lecture. Repetitive questions have been merged into the clearest canonical version. Frequency noted where multiple students asked the same thing.

Q: Why do we need to remove duplicate records before clustering? A: If you have many copies of the same record, the statistical description (mean, spread) gets biased. One record repeated 100 times will heavily distort the mean. Even though it may not affect all measures equally, the statistical description is the foundation — from there it influences everything downstream: cluster centers, variance estimates, and ultimately the assignments. This applies to both K-means and GMM.
Q: When we "assume two random Gaussians," what exactly do we assume? A: We assume specific numeric values for \(\mu_1, \mu_2, \sigma_1, \sigma_2\). That's it. One Gaussian has a certain mean and standard deviation; the other has different values. These are the parameters that define each bell curve. "Random" here means "initial guesses," not "truly random from thin air" — in practice, Python uses K-means to get sensible starting values.
Q: (Multiple students asked variations) What if a point has equal probability of belonging to two clusters (50-50)? A: It's very unlikely that the probabilities are exactly equal, but if it happens, you can assign the point to either cluster — it doesn't matter. Algorithmically, this is handled with \(\leq\) or \(\geq\) conditions. In soft clustering, the assignment is probabilistic anyway, so a 50-50 split just means the point is genuinely ambiguous.
Q: (Multiple students asked) Do we need to calculate the dot products for ALL records in SVM? A: Practically, the algorithm computes dot products for all records during training. But after solving, the \(\alpha_i\) values become zero for everything except the support vectors. So for classification of new points, you effectively only need the support vectors. This sparsity — most \(\alpha_i = 0\) — is why the dual formulation is efficient in practice.
Q: What if the data has overlapping points in SVM? A: Remove exact duplicates before running the algorithm — they don't add information and can cause numerical issues. For points that are very close but not identical, hard-margin SVM may struggle to find a perfect separator. Soft-margin SVM (next lecture) handles overlapping classes explicitly by allowing some misclassifications with a penalty.
Q: Does the margin line always touch the support vectors? A: Conceptually, the margin lines are as close to the support vectors as possible without crossing them. When you compute the maximum margin, the margin lines may or may not exactly touch — they must be kept as close as possible. The professor's analogy: "When you're doing namaste, how far can you move your hands apart before touching someone on either side? When you touch someone on one side, that is the limit — you take that same distance on the other side too." In the formal hard-margin solution, the active constraints (support vectors) satisfy the equality \(y_i(\mathbf{w}^\top \mathbf{x}_i - b) = 1\) exactly.
Q: (Several students asked) How do we get from the primal to the dual problem? Where do the \(\alpha\) values come from? A: The \(\alpha\) values are Lagrangian multipliers — they come from the Lagrangian function used to convert the constrained optimization into a dual form. This involves KKT conditions and Lagrangian duality, studied in detail in the Mathematical Foundations for ML course. For the ML course, you only need the final formulas: \(f(\mathbf{x}) = \sum \alpha_i y_i (\mathbf{x}_i^\top \mathbf{x}) + b\), \(\mathbf{w} = \sum \alpha_i y_i \mathbf{x}_i\), and the formula for \(b\). The derivations are for conceptual understanding — "ML maybe will not ask" the derivations.
Q: Why is \(\mathbf{w}\) perpendicular to the hyperplane? A: This is standard vector algebra. For any hyperplane defined by \(\mathbf{w} \cdot \mathbf{x} - b = 0\), the gradient is \(\mathbf{w}\), and the gradient is always perpendicular to the level set. Another way: take any two points \(\mathbf{x}_a, \mathbf{x}_b\) on the hyperplane. Then \(\mathbf{w} \cdot \mathbf{x}_a = b\) and \(\mathbf{w} \cdot \mathbf{x}_b = b\), so \(\mathbf{w} \cdot (\mathbf{x}_a - \mathbf{x}_b) = 0\). Thus \(\mathbf{w}\) is perpendicular to every vector lying in the hyperplane — it is the normal vector.
Q: Do we need to solve the system of equations for SVM manually on the exam? A: Yes. You need to know how to write the system of linear equations using the classification function formula \(\sum_j \alpha_j y_j (\mathbf{x}_j^\top \mathbf{x}_i) = y_i\), and then solve it for the \(\alpha\) values. The professor's advice: "Just please study solving system of linear equations. Otherwise you will not be able to solve this here."

16.13 Key Industry Applications and Real-World Connections

  • GMM for unsupervised discovery — height data and beyond. The classic example: adult heights in a city come from two underlying distributions (men and women). GMM discovers these latent groups without ever seeing gender labels. This same pattern applies to several real-world tasks: customer segmentation (discovering spending-personality types from transaction data), anomaly detection (flagging points with low probability under the fitted GMM as outliers), and image segmentation. For image segmentation, the technique is known as vector quantization — each pixel is represented by its closest cluster center (Bishop §9.1.1).
  • SVM for binary classification — admissions, medicine, and finance. The motivating example uses CGPA and JEE scores for admission prediction — a realistic binary classification scenario. The same framework applies to: loan default prediction (will this borrower repay?), medical diagnosis (malignant vs. benign tumor from imaging features), spam detection (spam vs. not-spam from email features), and face detection (face vs. non-face from pixel intensities).
  • Large-dimensional data — why SVM's dual shines. The professor emphasized image data as the motivating case for the dual formulation. Images have thousands of pixels (features) but training sets may have only hundreds of images. In this \(n \ll d\) regime, the dual form reduces computation dramatically by working with dot products between data points rather than dot products with the weight vector. The same advantage applies to text classification with bag-of-words features (vocabulary size = \(d \gg n\)).
  • Python implementations — K-means initializes GMM. scikit-learn's GaussianMixture uses K-means to initialize cluster centers, covariances, and mixing weights before running EM. This gives faster, more reliable convergence. Similarly, sklearn.svm.SVC implements both linear and kernel SVMs with efficient solvers (SMO, libsvm).
  • Nonlinear SVM — the kernel trick (next lecture). The professor previewed that nonlinear SVM handles data that is not linearly separable. By replacing dot products \(\mathbf{x}_i^\top \mathbf{x}_j\) with kernel functions \(k(\mathbf{x}_i, \mathbf{x}_j)\), the SVM can learn nonlinear decision boundaries while keeping the same optimization framework. The popular Gaussian (RBF) kernel \(k(\mathbf{x}_i, \mathbf{x}_j) = \exp(-\gamma \|\mathbf{x}_i - \mathbf{x}_j\|^2)\) is the default in most libraries.
  • Soft margin SVM — the practical default. Virtually all real-world SVM applications use soft margin (with slack variables \(\xi_n\) and a regularization parameter \(C\)) because real data always has noise and overlapping classes. Hard margin is primarily a theoretical building block that leads to the more practical soft-margin formulation.

Gaussian Mixture Models — Soft Clustering and Mixture Concept

Must-know: GMM is a probabilistic clustering model that assigns each data point a soft membership — a probability distribution over clusters — rather than a hard binary assignment. The model assumes data is generated from a weighted sum (mixture) of K Gaussian distributions, each with its own mean \(\mu_k\), variance \(\sigma_k^2\), and mixing coefficient \(\pi_k\) (where \(\sum_{k=1}^{K} \pi_k = 1\)).

\[ p(x) = \sum_{k=1}^{K} \pi_k \cdot \frac{1}{\sqrt{2\pi\sigma_k^2}} \exp\left(-\frac{(x - \mu_k)^2}{2\sigma_k^2}\right) \]

⚠️ Top pitfall: Forgetting the mixing coefficient constraint \(\sum \pi_k = 1\). Students often treat \(\pi_k\) as free parameters — they are probabilities and must sum to 1.

Self-check: How does GMM differ from K-means in terms of (a) cluster assignment and (b) cluster shape?

Expectation-Maximization Algorithm for GMM

Must-know: The EM algorithm alternates between two steps. E-step: Compute responsibilities \(r_{ik}\) — the probability that point \(i\) belongs to component \(k\). M-step: Update parameters \(\mu_k, \sigma_k^2, \pi_k\) using weighted averages. Repeat until log-likelihood stabilizes. Every point always has fractional membership — no point is ever 100% in one cluster.

\[ r_{ik} = \frac{\pi_k \cdot \mathcal{N}(x_i \mid \mu_k, \sigma_k^2)}{\sum_{j=1}^{K} \pi_j \cdot \mathcal{N}(x_i \mid \mu_j, \sigma_j^2)} \quad \text{(E-step)} \] \[ \mu_k^{\text{new}} = \frac{\sum_{i=1}^{n} r_{ik} \cdot x_i}{\sum_{i=1}^{n} r_{ik}} \quad \text{(M-step mean update)} \]

⚠️ Top pitfall: Confusing the E-step and M-step formulas. The responsibility formula (E-step) uses the current parameters. The M-step formula uses the responsibilities just computed in the E-step. Also: forgetting that EM can converge to local optima.

Self-check: If \(\mu_1 = 0\) and \(\mu_2 = 5\) with \(\sigma_1^2 = \sigma_2^2 = 1\) and equal mixing coefficients, what is the approximate responsibility of \(x = 0\) for component 1?

Connects to: GMM model definition, convergence criteria (log-likelihood threshold \(\varepsilon\)), K-means EM analogy, local optima problem.

GMM Worked Example — 4-Point Dataset

Must-know: The canonical exam problem: fit \(K = 2\) Gaussians to points \(\{0, 1, 2, 3\}\). Initialize: \(\mu_1 = 0.5, \mu_2 = 2.5, \sigma_1^2 = \sigma_2^2 = 1, \pi_1 = \pi_2 = 0.5\). Run one full EM iteration. After E-step, responsibilities approximately: \(r_{0,1} \approx 0.95, r_{1,1} \approx 0.80, r_{2,1} \approx 0.20, r_{3,1} \approx 0.05\). After M-step, \(\mu_1^{\text{new}} \approx 0.68\)–\(0.71\), \(\mu_2^{\text{new}} \approx 2.29\)–\(2.33\), \(\sigma_1^2, \sigma_2^2\) shrink to ~0.62. Both means move toward their natural clusters — variances tighten.

\[ \mu_1^{\text{new}} = \frac{\sum_i r_{i,1} \cdot x_i}{\sum_i r_{i,1}}, \quad \sigma_1^{2,\text{new}} = \frac{\sum_i r_{i,1} \cdot (x_i - \mu_1^{\text{new}})^2}{\sum_i r_{i,1}}, \quad \pi_k^{\text{new}} = \frac{1}{n}\sum_i r_{ik} \]

⚠️ Top pitfall: Using the updated mean in the variance formula but forgetting to use it in the squared deviation term \((x_i - \mu_k^{\text{new}})^2\). Also: not checking that responsibilities sum to 1 for each point.

Self-check: After the first M-step, why do the mixing coefficients stay at 0.5 for this symmetric dataset?

GMM Practical Considerations — Choosing K, Initialization, and Convergence

Must-know: Choosing K: Use BIC (\(\text{BIC} = -2\log L + K_{\text{params}} \ln n\)) or AIC (\(\text{AIC} = -2\log L + 2K_{\text{params}}\)) — lower is better. BIC penalizes complexity more heavily. Initialization: K-means first (scikit-learn default) gives reliable starting positions. Convergence: Stop when \(|\mathcal{L}^{(t+1)} - \mathcal{L}^{(t)}| < \varepsilon\) (typically \(10^{-3}\)).

\[ \text{BIC} = -2 \log L + K_{\text{params}} \cdot \ln(n), \quad \text{AIC} = -2 \log L + 2 K_{\text{params}} \]

⚠️ Top pitfall: Using BIC/AIC with too few candidate K values (just K=2,3,4). Always test a range and look for the minimum. Also: confusing which is lower-is-better — both BIC and AIC are lower-is-better.

Support Vector Machines — Margin Maximization Concept

Must-know: SVM finds the hyperplane that maximizes the margin between two classes. The margin is \(2 / \|\mathbf{w}\|\). The support vectors are the data points closest to the decision boundary — they are the only points that determine \(\mathbf{w}\) and \(b\). Moving any non-support-vector point does NOT change the boundary. This sparsity is the key computational property of SVMs.

\[ \text{Decision boundary: } \mathbf{w} \cdot \mathbf{x} - b = 0, \quad \text{Margin lines: } \mathbf{w} \cdot \mathbf{x} - b = \pm 1, \quad \text{Margin width: } \frac{2}{\|\mathbf{w}\|} \]

⚠️ Top pitfall: Confusing the decision boundary (\(\mathbf{w} \cdot \mathbf{x} - b = 0\)) with the margin lines (\(\mathbf{w} \cdot \mathbf{x} - b = \pm 1\)). Also: thinking hard-margin SVM works when data is not linearly separable — it doesn't.

SVM Mathematical Formulation — Primal Problem

Must-know: The SVM primal problem minimizes \(\frac{1}{2}\|\mathbf{w}\|^2\) subject to \(y_i(\mathbf{w} \cdot \mathbf{x}_i - b) \geq 1\) for all \(i\). The factor \(1/2\) is for derivative convenience. The elegant constraint trick \(y_i(\mathbf{w} \cdot \mathbf{x}_i - b) \geq 1\) covers both classes in one inequality. The margin is derived by walking \(K = 1/\|\mathbf{w}\|\) units along the normal direction \(\mathbf{w}\) from the decision boundary to either margin line.

\[ \min_{\mathbf{w}, b} \frac{1}{2} \|\mathbf{w}\|^2 \quad \text{s.t.} \quad y_i (\mathbf{w} \cdot \mathbf{x}_i - b) \geq 1 \; \forall i \]

⚠️ Top pitfall: Forgetting that the constraint uses \(\geq 1\) (not \(\geq 0\)). The 1 comes from the margin line equations \(\mathbf{w} \cdot \mathbf{x} - b = \pm 1\). Also: not understanding why \(\mathbf{w}\) is perpendicular to the hyperplane — this is fundamental to the margin derivation.

Self-check: Derive why the distance from the decision boundary to one margin line is \(1/\|\mathbf{w}\|\).

Connects to: Margin width derivation, normal vector concept, quadratic programming, KKT conditions, dual formulation.

SVM Lagrangian Dual — From Primal to Dual

Must-know: The dual formulation transforms the problem from optimizing over \(\mathbf{w} \in \mathbb{R}^d\) to optimizing over \(n\) Lagrangian multipliers \(\alpha_i \geq 0\). The key result: \(\mathbf{w} = \sum_i \alpha_i y_i \mathbf{x}_i\). Only support vectors have \(\alpha_i > 0\) (all others are zero). The dual is more efficient when \(n \ll d\). For classification: \(f(\mathbf{x}) = \sum_i \alpha_i y_i (\mathbf{x}_i^\top \mathbf{x}) + b\).

\[ \mathbf{w} = \sum_{i=1}^{n} \alpha_i y_i \mathbf{x}_i, \quad f(\mathbf{x}) = \sum_{i=1}^{n} \alpha_i y_i (\mathbf{x}_i^\top \mathbf{x}) + b, \quad \sum_{i=1}^{n} \alpha_i y_i = 0 \]

⚠️ Top pitfall: Forgetting the constraint \(\sum_i \alpha_i y_i = 0\). This comes from setting \(\partial \mathcal{L}/\partial b = 0\) and is an essential constraint on the \(\alpha_i\) values. Also: thinking Lagrangian derivations are required for the exam — they are for understanding only.

Self-check: Why are most \(\alpha_i = 0\) after solving the SVM dual? What condition makes an \(\alpha_i\) non-zero?

Connects to: Primal optimization, KKT complementary slackness, support vector sparsity, kernel trick (next lecture), bias computation.

SVM Worked Example — 3-Point Dataset with Bias Column

Must-know: The canonical exam problem: 3 points with augmented bias column of 1. \(\mathbf{x}_1 = (0,1,1), y_1 = -1\); \(\mathbf{x}_2 = (-1,3,1), y_2 = +1\); \(\mathbf{x}_3 = (1,3,1), y_3 = +1\). Solve the system \(\sum_j \alpha_j y_j (\mathbf{x}_j^\top \mathbf{x}_i) = y_i\) for each \(i\). Solution: \(\alpha_1 = 3.5, \alpha_2 = \alpha_3 = 0.75\). Result: \(\mathbf{w} = (0, 1, -2)\), decision boundary \(x_2 = 2\).

\[ f(\mathbf{x}) = \sum_{j} \alpha_j y_j (\mathbf{x}_j^\top \mathbf{x}) + b, \quad \mathbf{w} = \sum_i \alpha_i y_i \mathbf{x}_i, \quad b = -w_3 \; \text{(bias component)} \]

⚠️ Top pitfall: Forgetting to include the bias column of 1 in the feature vectors when computing dot products. The third component "1" absorbs \(b\) into \(\mathbf{w}\) so that the decision boundary equation becomes \(\mathbf{w} \cdot \mathbf{x} = 0\) instead of \(\mathbf{w} \cdot \mathbf{x} - b = 0\). Also: arithmetic errors in solving the 3×3 linear system — practice this.

Self-check: Verify that each support vector lies exactly on its respective margin line (\(x_2 = 1\) for negative, \(x_2 = 3\) for positive).

Connects to: Classification function, system of linear equations, support vector identification, margin verification, bias extraction from augmented weight vector.
