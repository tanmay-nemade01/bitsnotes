4.1 Skip-Gram with Negative Sampling (SGNS) Recap

4.1.1 Core Idea and Intuition

Intuition: Imagine a security guard checking stadium tickets. To check one person's ticket (the true context word), inspecting every single fan in a 100,000-seat stadium (the full Softmax denominator over vocabulary size \(V\)) takes forever. Negative sampling simplifies this to a spot check: the guard verifies the ticket holder (positive pair) and checks 5 random people nearby (negative pairs).

Skip-Gram with Negative Sampling (SGNS) is a prediction-based static word embedding algorithm introduced by Mikolov et al. Given a target word token \(w\), SGNS predicts whether candidate context words fall within a fixed sliding window size of \(w\). Instead of computing a computationally prohibitive multi-class Softmax normalization across the entire vocabulary size \(V\), SGNS reformulates training as a series of binary classification tasks. For every target word, the model processes one positive context word \(c^+\) (which actually co-occurred within the context window in the corpus) alongside \(K\) noise-sampled negative context words \(c^-_k\) drawn from a smoothed noise distribution \(P_n(w) \propto U(w)^{3/4}\).

Static word embeddings assign each unique word token in vocabulary \(V\) a fixed-dimensional dense vector in \(\mathbb{R}^d\). Once training completes, these vectors remain constant regardless of the surrounding sentence context during inference. Although contextual architectures like Transformers dominate contemporary NLP, static embeddings like SGNS, CBOW, and GloVe remain indispensable in production because they execute with extreme speed on standard CPUs without requiring expensive GPU infrastructure.

4.1.2 Symbol Registry

  • \(w\) — Target word token (string identifier in vocabulary \(V\))
  • \(c^+\) — Positive context word token (token co-occurring with \(w\) within sliding window)
  • \(c^-_k\) — \(k\)-th negative context word token (token sampled from noise distribution \(P_n\))
  • \(K\) — Number of negative samples per positive pair (scalar integer, typically \(5 \le K \le 20\))
  • \(\mathbf{v}_w\) — Target word embedding vector in \(\mathbb{R}^d\)
  • \(\mathbf{u}_c\) — Context word embedding vector in \(\mathbb{R}^d\)
  • \(z\) — Pre-activation dot product score (\(\mathbf{v}_w^\top \mathbf{u}_c \in \mathbb{R}\))
  • \(\sigma(z) \) — Logistic sigmoid activation function (\(\frac{1}{1 + e^{-z}} \in (0, 1) \))
  • \(\eta\) — Learning rate hyperparameter (scalar in \(\,\(0, \infty) \))
  • \(y\) — Binary ground-truth label (\(y=1\) for positive context, \(y=0\) for negative context)
  • \(e_c\) — Prediction error difference (\(\sigma(\mathbf{v}_w^\top \mathbf{u}_c) - y\))

4.1.3 Mathematical Formulation: Vector Updates and Gradient Descent Walkthrough

Formalization: SGNS replaces \(V\)-way Softmax classification with binary logistic regression. The conditional probability that context word \(c\) is a true positive context word for target word \(w\) is:

\[ P(D=1 \mid w, c) = \sigma(\mathbf{v}_w^\top \mathbf{u}_c) = \frac{1}{1 + e^{-\mathbf{v}_w^\top \mathbf{u}_c}} \]

The probability that pair \(\,\(w, c) \) is a negative noise pair (\(D=0\)) is:

\[ P(D=0 \mid w, c) = 1 - \sigma(\mathbf{v}_w^\top \mathbf{u}_c) = \sigma(-\mathbf{v}_w^\top \mathbf{u}_c) \]

For a target word \(w\), true positive context \(c^+\), and \(K\) negative samples \(\{c^-_1, c^-_2, \dots, c^-_K\}\), the joint objective function to maximize is the log-likelihood of correctly classifying both positive and negative pairs:

\[ \mathcal{L}_{\text{SGNS}}(\mathbf{v}_w, \mathbf{u}_{c^+}, \mathbf{u}_{c^-}) = \log \sigma(\mathbf{v}_w^\top \mathbf{u}_{c^+}) + \sum_{k=1}^K \log \sigma(-\mathbf{v}_w^\top \mathbf{u}_{c^-_k}) \]

To minimize the corresponding negative log-likelihood loss \(J(\theta) = -\mathcal{L}_{\text{SGNS}}\), we derive the partial derivative with respect to target vector \(\mathbf{v}_w\) using the identity \(\frac{d}{dx} \log \sigma(x) = 1 - \sigma(x) \):

\[ \begin{aligned} \frac{\partial J}{\partial \mathbf{v}_w} &= -\frac{\partial}{\partial \mathbf{v}_w} \left[ \log \sigma(\mathbf{v}_w^\top \mathbf{u}_{c^+}) + \sum_{k=1}^K \log \sigma(-\mathbf{v}_w^\top \mathbf{u}_{c^-_k}) \right] \\ &= -\left(1 - \sigma(\mathbf{v}_w^\top \mathbf{u}_{c^+})\right) \mathbf{u}_{c^+} - \sum_{k=1}^K \left(1 - \sigma(-\mathbf{v}_w^\top \mathbf{u}_{c^-_k})\right) (-\mathbf{u}_{c^-_k}) \\ &= \left(\sigma(\mathbf{v}_w^\top \mathbf{u}_{c^+}) - 1\right) \mathbf{u}_{c^+} + \sum_{k=1}^K \sigma(\mathbf{v}_w^\top \mathbf{u}_{c^-_k}) \mathbf{u}_{c^-_k} \end{aligned} \]

Using stochastic gradient descent with learning rate \(\eta\), the updated target word embedding \(\mathbf{v}_w^{(\text{new})}\) is:

\[ \mathbf{v}_w^{(\text{new})} = \mathbf{v}_w^{(\text{old})} - \eta \cdot \left[ (\sigma(\mathbf{v}_w^\top \mathbf{u}_{c^+}) - 1)\mathbf{u}_{c^+} + \sum_{k=1}^K \sigma(\mathbf{v}_w^\top \mathbf{u}_{c^-_k})\mathbf{u}_{c^-_k} \right] \]

Similarly, context vector updates for positive context \(\mathbf{u}_{c^+}\) and negative context \(\mathbf{u}_{c^-_k}\) follow:

\[ \mathbf{u}_{c^+}^{(\text{new})} = \mathbf{u}_{c^+}^{(\text{old})} - \eta \cdot (\sigma(\mathbf{v}_w^\top \mathbf{u}_{c^+}) - 1)\mathbf{v}_w^{(\text{old})} \] \[ \mathbf{u}_{c^-_k}^{(\text{new})} = \mathbf{u}_{c^-_k}^{(\text{old})} - \eta \cdot \sigma(\mathbf{v}_w^\top \mathbf{u}_{c^-_k})\mathbf{v}_w^{(\text{old})} \]

4.1.4 Worked Example: Numerical SGNS Gradient Update

Numerical Walkthrough:

Consider a 2-dimensional vector space (\(d=2\)) with learning rate \(\eta = 0.05\).

Target word \(w = \text{"Ned"}\) has initial vector \(\mathbf{v}_{\text{Ned}} = [0.80, 0.40]^\top\).

Positive context word \(c^+ = \text{"Stark"}\) has initial vector \(\mathbf{u}_{\text{Stark}} = [0.60, 0.80]^\top\).

One negative context word (\(K=1\)) \(c^- = \text{"zebra"}\) has vector \(\mathbf{u}_{\text{zebra}} = [-0.50, 0.50]^\top\).

Step 1: Compute positive pair dot product and probability.

\[ z^+ = \mathbf{v}_{\text{Ned}}^\top \mathbf{u}_{\text{Stark}} = (0.80 \times 0.60) + (0.40 \times 0.80) = 0.48 + 0.32 = 0.80 \] \[ \sigma(z^+) = \frac{1}{1 + e^{-0.80}} \approx \frac{1}{1 + 0.4493} \approx \mathbf{0.6900} \]

Positive prediction error: \(e_{\text{Stark}} = \sigma(z^+) - 1 = 0.6900 - 1.0 = \mathbf{-0.3100}\).

Step 2: Compute negative pair dot product and probability.

\[ z^- = \mathbf{v}_{\text{Ned}}^\top \mathbf{u}_{\text{zebra}} = (0.80 \times -0.50) + (0.40 \times 0.50) = -0.40 + 0.20 = -0.20 \] \[ \sigma(z^-) = \frac{1}{1 + e^{0.20}} \approx \frac{1}{1 + 1.2214} \approx \mathbf{0.4502} \]

Negative prediction error: \(e_{\text{zebra}} = \sigma(z^-) - 0 = \mathbf{0.4502}\).

Step 3: Compute overall gradient w.r.t. target vector \(\mathbf{v}_{\text{Ned}}\).

\[ \begin{aligned} \nabla_{\mathbf{v}_{\text{Ned}}} J &= e_{\text{Stark}} \cdot \mathbf{u}_{\text{Stark}} + e_{\text{zebra}} \cdot \mathbf{u}_{\text{zebra}} \\ &= -0.3100 \begin{bmatrix} 0.60 \\ 0.80 \end{bmatrix} + 0.4502 \begin{bmatrix} -0.50 \\ 0.50 \end{bmatrix} \\ &= \begin{bmatrix} -0.1860 \\ -0.2480 \end{bmatrix} + \begin{bmatrix} -0.2251 \\ 0.2251 \end{bmatrix} = \begin{bmatrix} -0.4111 \\ -0.0229 \end{bmatrix} \end{aligned} \]

Step 4: Update target vector \(\mathbf{v}_{\text{Ned}}\).

\[ \mathbf{v}_{\text{Ned}}^{(\text{new})} = \begin{bmatrix} 0.80 \\ 0.40 \end{bmatrix} - 0.05 \begin{bmatrix} -0.4111 \\ -0.0229 \end{bmatrix} = \begin{bmatrix} 0.80 + 0.02056 \\ 0.40 + 0.00115 \end{bmatrix} = \mathbf{\begin{bmatrix} 0.8206 \\ 0.4011 \end{bmatrix}} \]

Sense check: \(\mathbf{v}_{\text{Ned}}\) nudged closer to \(\mathbf{u}_{\text{Stark}}\) (attraction) and shifted away from \(\mathbf{u}_{\text{zebra}}\) (repulsion).

4.1.5 Assumptions & Scope

Scope & Assumptions:

  • IID co-occurrence assumption: SGNS assumes word pairs in context windows are drawn independently given the target word.
  • Unigram noise sampling assumption: Negative samples are drawn independently of target \(w\) using \(P_n(w) \propto U(w)^{3/4}\).
  • Loss of word order: SGNS treats context window as an unordered bag of context tokens, discarding local grammar and word sequence structure.

4.1.6 Visual Intuition

In vector space, training acts like an elastic spring system. The positive context vector \(\mathbf{u}_{c^+}\) exerts an attractive force pulling target vector \(\mathbf{v}_w\) closer in direction and magnitude. Concurrently, each negative context vector \(\mathbf{u}_{c^-_k}\) exerts a repulsive force pushing \(\mathbf{v}_w\) away. Over thousands of mini-batch iterations, semantically related words coalesce into tight spatial clusters while unrelated words are driven apart.

4.1.7 Pitfalls

Common Traps:

  1. Unsmoothed unigram noise sampling: Sampling negative words directly from raw corpus unigram frequencies \(U(w) \) causes ultra-frequent stop words (the, is) to dominate negative updates while rare domain words are never sampled.
  2. Ignoring data quality: Garbage in, garbage out. Vector spaces directly mirror human, social, and structural biases in raw training text.
  3. Confusing static with contextual embeddings: Static vectors cannot resolve polysemous words (bank as financial institution vs river bank); a single static vector averages all senses together.

4.1.9 Context Window Size and Domain Adaptation

The choice of window size controls the semantic nature of learned representations:

  • Small context window (\(\pm 2\) words): Captures tight syntactic and functional similarities (e.g., co-hyponyms like cat / dog or verb inflections).
  • Large context window (\(\pm 4\) to \(\pm 10\) words): Captures broader topical and domain-level associations (e.g., doctor / hospital / treatment). Recommended for small or highly specialized domain-specific corpora (such as medical or legal documents) where co-occurrence evidence is sparse.

4.1.10 Recap and Bridge

Recap: SGNS replaces full Softmax over \(V\) with efficient binary classification using \(1\) positive pair and \(K\) negative pairs, achieving \(O(K) \) per-token training time.

Exam note: Expect SGNS numerical problems asking you to compute dot products, sigmoid activation values, prediction error terms, and single-step weight updates.

4.1.11 Relevance, Production Applications, and Data Quality

In production engineering, static SGNS embeddings are heavily utilized in search retrieval, candidate generation, real-time recommendation engines, and low-latency edge deployments. Because static vector lookups cost \(O(1) \) time via array indexing, they run efficiently on standard local CPUs without high-latency GPU inference calls.

However, data quality remains paramount. Biases embedded in training text are faithfully encoded in the vector space. Responsible AI workflows mandate data preprocessing, debiasing projections, and rigorous evaluation before releasing embeddings into customer-facing applications.

4.2 Continuous Bag of Words (CBOW)

4.2.1 Core Intuition and Architecture

Intuition: Imagine a fill-in-the-blank puzzle: "The _____ purred on the mat." Instead of taking one word and predicting many surrounding context words (like Skip-Gram), Continuous Bag of Words (CBOW) pools together all surrounding context clues—like "The", "purred", "on", "the", "mat"—averages their vector representations into a single combined context vector, and uses that composite vector to predict the missing target word ("cat").

Continuous Bag of Words (CBOW) is the structural inverse of the Skip-Gram architecture. In CBOW, the model receives a continuous bag of context words \(C = \{c_1, c_2, \dots, c_C\}\) surrounding a target position and computes a conditional probability distribution over the entire vocabulary \(V\) to predict the target word token \(w_t\).

CBOW utilizes a two-matrix representation: an input context matrix \(\mathbf{W}_{\text{in}} \in \mathbb{R}^{|V| \times d}\) (where each row represents input context vector \(\mathbf{u}_c \in \mathbb{R}^d\)) and an output target matrix \(\mathbf{W}_{\text{out}} \in \mathbb{R}^{d \times |V|}\) (where each column represents target vector \(\mathbf{v}_w \in \mathbb{R}^d\)). Because context vectors are averaged across the window, CBOW treats the context window as a unordered "bag", averaging out positional order while rapidly building smooth representations for high-frequency words.

4.2.2 Symbol Registry

  • \(C\) — Context window size (number of context words surrounding target position, \(C = 2 \times \text{window\_radius}\))
  • \(c_i\) — \(i\)-th surrounding context word token in window
  • \(\mathbf{u}_{c_i}\) — Input context vector representation for word \(c_i\) in \(\mathbb{R}^d\) (row of \(\mathbf{W}_{\text{in}}\))
  • \(\mathbf{\bar{u}}\) — Aggregate average context vector representation in \(\mathbb{R}^d\)
  • \(w_j\) — \(j\)-th candidate target word token in vocabulary \(V\)
  • \(\mathbf{v}_{w_j}\) — Output target vector representation for candidate word \(w_j\) in \(\mathbb{R}^d\) (column of \(\mathbf{W}_{\text{out}}\))
  • \(z_j\) — Unnormalized logit score for candidate target word \(w_j\) (\(z_j = \mathbf{v}_{w_j}^\top \mathbf{\bar{u}} \in \mathbb{R}\))
  • \(P(w_j \mid c_1, \dots, c_C) \) — Softmax probability of target word \(w_j\) given context bag

4.2.3 Mathematical Formulation: Softmax Output for Target Word Prediction

Formalization: Given \(C\) surrounding context words, CBOW computes the linear projection of the hidden layer by averaging the context word vectors:

\[ \mathbf{\bar{u}} = \frac{1}{C} \sum_{i=1}^C \mathbf{u}_{c_i} \]

Next, the model computes unnormalized logit scores \(z_j\) for every candidate target word \(w_j \in V\) via dot product with target vectors \(\mathbf{v}_{w_j}\):

\[ z_j = \mathbf{v}_{w_j}^\top \mathbf{\bar{u}} \]

To normalize these logit scores into a valid probability distribution over all \(|V|\) vocabulary words, CBOW applies multi-class Softmax:

\[ P(w_j \mid c_1, \dots, c_C) = \frac{\exp(\mathbf{v}_{w_j}^\top \mathbf{\bar{u}})}{\sum_{k=1}^{|V|} \exp(\mathbf{v}_{w_k}^\top \mathbf{\bar{u}})} \]

Training minimizes the cross-entropy loss \(\mathcal{L}_{\text{CBOW}} = -\log P(w_{\text{true}} \mid c_1, \dots, c_C) \) using stochastic gradient descent.

4.2.4 Worked Example: Numerical CBOW Forward Pass and Prediction

Numerical Walkthrough:

Consider a tiny vocabulary \(V = \{\text{"cat"}, \text{"dog"}, \text{"mat"}\}\) with \(|V|=3\) and \(d=2\).

Context window size \(C=2\) with context words \(c_1 = \text{"The"}\) (mapped to vector \(\mathbf{u}_1 = [1.0, 2.0]^\top\)) and \(c_2 = \text{"on"}\) (mapped to vector \(\mathbf{u}_2 = [3.0, 0.0]^\top\)).

Target vectors in \(\mathbf{W}_{\text{out}}\):

  • \(\mathbf{v}_{\text{cat}} = [0.5, 1.5]^\top\)
  • \(\mathbf{v}_{\text{dog}} = [1.0, 0.5]^\top\)
  • \(\mathbf{v}_{\text{mat}} = [0.0, 2.0]^\top\)

Step 1: Compute aggregate context vector \(\mathbf{\bar{u}}\).

\[ \mathbf{\bar{u}} = \frac{1}{2} (\mathbf{u}_1 + \mathbf{u}_2) = \frac{1}{2} \left( \begin{bmatrix} 1.0 \\ 2.0 \end{bmatrix} + \begin{bmatrix} 3.0 \\ 0.0 \end{bmatrix} \right) = \frac{1}{2} \begin{bmatrix} 4.0 \\ 2.0 \end{bmatrix} = \mathbf{\begin{bmatrix} 2.0 \\ 1.0 \end{bmatrix}} \]

Step 2: Compute unnormalized logit scores \(z_j = \mathbf{v}_j^\top \mathbf{\bar{u}}\).

\[ z_{\text{cat}} = (0.5 \times 2.0) + (1.5 \times 1.0) = 1.0 + 1.5 = \mathbf{2.5} \] \[ z_{\text{dog}} = (1.0 \times 2.0) + (0.5 \times 1.0) = 2.0 + 0.5 = \mathbf{2.5} \] \[ z_{\text{mat}} = (0.0 \times 2.0) + (2.0 \times 1.0) = 0.0 + 2.0 = \mathbf{2.0} \]

Step 3: Exponentiate logits and compute Softmax denominator.

\[ e^{z_{\text{cat}}} = e^{2.5} \approx 12.1825 \] \[ e^{z_{\text{dog}}} = e^{2.5} \approx 12.1825 \] \[ e^{z_{\text{mat}}} = e^{2.0} \approx 7.3891 \] \[ \text{Denominator } \sum_{k=1}^3 e^{z_k} = 12.1825 + 12.1825 + 7.3891 = \mathbf{31.7541} \]

Step 4: Compute normalized Softmax probabilities.

\[ P(\text{"cat"}) = \frac{12.1825}{31.7541} \approx \mathbf{0.3836} \quad (38.36\%) \] \[ P(\text{"dog"}) = \frac{12.1825}{31.7541} \approx \mathbf{0.3836} \quad (38.36\%) \] \[ P(\text{"mat"}) = \frac{7.3891}{31.7541} \approx \mathbf{0.2327} \quad (23.27\%) \]

Sense check: Sum of probabilities \(= 0.3836 + 0.3836 + 0.2327 = 0.9999 \approx 1.0\). Words "cat" and "dog" tie with highest predicted probability.

4.2.5 Assumptions & Scope

Scope & Assumptions:

  • Bag-of-words context invariance: Averaging context vectors treats surrounding words as an unordered multiset, ignoring word order and syntactic distance within the window.
  • Single target prediction bottleneck: CBOW generates a single prediction per window, compressing context information into a single mean vector.
  • Softmax vocabulary bottleneck: Standard CBOW requires computing dot products across all \(|V|\) words in the denominator unless Hierarchical Softmax or Negative Sampling is applied.

4.2.6 Visual Intuition

Architecturally, CBOW operates as a shallow 3-layer neural network:

  1. Input layer: \(C\) sparse one-hot vectors \(\mathbf{x}_{c_1}, \dots, \mathbf{x}_{c_C} \in \{0,1\}^{|V|}\).
  2. Hidden layer: Vector average node performing \(\mathbf{\bar{u}} = \frac{1}{C} \sum_{i=1}^C \mathbf{W}_{\text{in}}^\top \mathbf{x}_{c_i}\). No non-linear activation function is applied at the hidden layer.
  3. Output layer: Dense linear projection matrix \(\mathbf{W}_{\text{out}}\) followed by a Softmax normalization node across all \(|V|\) vocabulary slots.

4.2.7 Pitfalls

Common Traps:

  1. Confusing Sigmoid and Softmax: Sigmoid maps a single scalar to \(\,\(0,1) \) for independent binary decisions. Softmax normalizes a vector of logits into a mutually exclusive probability distribution that sums to 1 across the vocabulary.
  2. Over-smoothing rare words: Because CBOW averages context vectors, frequent stop words can dominate the mean vector \(\mathbf{\bar{u}}\), diluting the distinct signals of rare context words.

4.2.9 Student Questions and Answers

Q: What is the fundamental difference between the Sigmoid function and the Softmax function?

A: Sigmoid maps a single scalar score into a probability range between 0 and 1, making it suitable for binary classification (such as SGNS positive vs. negative pairs). Softmax takes an unnormalized vector of scores for multiple classes, exponentiates each score, and divides by the total sum of exponentiated scores. This creates a proper probability distribution across all classes where all output values lie between 0 and 1 and sum to 1. Softmax is used in multi-class prediction tasks like CBOW target word prediction.

Q: Does CBOW compute target word probabilities across the entire vocabulary for every sentence?

A: Yes, the standard Softmax denominator evaluates dot products across all unique words in vocabulary \(V\) to compute normalized probabilities during target prediction. In practical large-vocabulary implementations, Negative Sampling or Hierarchical Softmax is substituted to avoid computing all \(|V|\) exponentials.

4.2.10 Recap and Bridge

Recap: CBOW averages surrounding context vectors to predict the center target word, offering fast training over large text corpora.

Exam note: Expect comparative questions contrasting CBOW and Skip-Gram regarding prediction direction, rare vs. frequent word accuracy, and computational efficiency.

4.2.11 Relevance and Production Applications

CBOW is frequently selected when training word embeddings from scratch on massive, web-scale corpora (tens of billions of tokens) where training speed is the primary bottleneck. Its context-averaging mechanism acts as a regularizer against noisy individual co-occurrences in uncurated web text.

4.3 Global Vectors for Word Representation (GloVe)

4.3.1 Motivation: Combining Frequency and Prediction Paradigms

Intuition: Word representation algorithms historically belonged to two separate camps: global matrix factorization (like LSA), which compiles corpus-wide statistics but struggles with vector analogy arithmetic, and local prediction models (like Word2Vec), which excel at analogies but process tiny local context windows independently. GloVe bridges this divide: it first builds a global co-occurrence matrix \(X\) across the full corpus, then trains vectors to fit log co-occurrence ratios directly via efficient weighted least squares.

Before the introduction of GloVe by Pennington et al. (Stanford University), word representation methods were divided into two main paradigms:

  1. Frequency-based methods (Global Matrix Factorization): Algorithms like Latent Semantic Analysis (LSA) and hyperspace analogue to language (HAL) construct word-document or word-word co-occurrence matrices. They leverage global corpus statistics efficiently, but their vector spaces lack clean linear structures for word analogies (such as \(\text{"king"} - \text{"man"} + \text{"woman"} \approx \text{"queen"}\)).
  2. Prediction-based methods (Local Context Window): Algorithms like Skip-Gram and CBOW scan local context windows iteratively. They learn dense vector spaces with rich linear substructures and analogy properties, but they fail to exploit global co-occurrence statistics directly because they scan local sliding windows repeatedly.

GloVe (Global Vectors for Word Representation) synthesizes the advantages of both paradigms by training a log-bilinear regression model directly on non-zero entries of a global word-word co-occurrence matrix \(X\).

4.3.2 Symbol Registry

  • \(X\) — Global word-word co-occurrence matrix (\(X \in \mathbb{Z}_{\ge 0}^{|V| \times |V|}\))
  • \(X_{ij}\) — Co-occurrence count of target word \(i\) and context word \(j\) within sliding window
  • \(X_i\) — Total co-occurrence count of word \(i\) across all vocabulary terms (\(\sum_k X_{ik}\))
  • \(P_{ij}\) — Conditional probability of observing word \(j\) given word \(i\) (\(P(j \mid i) = X_{ij} / X_i\))
  • \(\frac{P_{ik}}{P_{jk}}\) — Ratio of co-occurrence probabilities for probe word \(k\) given target words \(i\) and \(j\)
  • \(\mathbf{w}_i\) — Target word embedding vector in \(\mathbb{R}^d\)
  • \(\mathbf{\tilde{w}}_j\) — Context word embedding vector in \(\mathbb{R}^d\)
  • \(b_i, \tilde{b}_j\) — Target and context scalar bias terms in \(\mathbb{R}\)
  • \(f(X_{ij}) \) — Bounded weighting function to prevent frequent stop-word dominance
  • \(x_{\max}, \alpha\) — Weighting function hyperparameters (typically \(x_{\max} = 100, \alpha = 0.75\))

4.3.3 The Co-occurrence Matrix and Probability Ratios

GloVe constructs a global co-occurrence matrix \(X\) where entry \(X_{ij}\) counts how many times context word \(j\) appears within a sliding context window (e.g., \(\pm 5\) words) of target word \(i\) across the entire text corpus.

The conditional co-occurrence probability \(P_{ij} = P(j \mid i) \) is computed as:

\[ P_{ij} = \frac{X_{ij}}{X_i} = \frac{X_{ij}}{\sum_{k=1}^{|V|} X_{ik}} \]

The core insight of GloVe is that raw co-occurrence probabilities \(P_{ij}\) contain background frequency noise. Comparing the ratio of conditional probabilities \(\frac{P_{ik}}{P_{jk}}\) for a probe word \(k\) relative to two target words \(i\) and \(j\) cleanly isolates distinguishing semantic properties from non-informative background noise.

4.3.4 Mathematical Formulation of the GloVe Objective

Formalization: GloVe requires the dot product of target vector \(\mathbf{w}_i\) and context vector \(\mathbf{\tilde{w}}_j\) plus bias terms to equal the natural logarithm of their co-occurrence count \(\log X_{ij}\):

\[ \mathbf{w}_i^\top \mathbf{\tilde{w}}_j + b_i + \tilde{b}_j = \log X_{ij} \]

To fit this log-bilinear model across all non-zero co-occurrences in global matrix \(X\), GloVe minimizes the weighted least-squares loss function \(\mathcal{J}\):

\[ \mathcal{J} = \sum_{i=1}^{|V|} \sum_{j=1}^{|V|} f(X_{ij}) \left( \mathbf{w}_i^\top \mathbf{\tilde{w}}_j + b_i + \tilde{b}_j - \log X_{ij} \right)^2 \]

The weighting function \(f(X_{ij}) \) saturates at \(x_{\max}\) to ensure that frequent stop words (such as the, is) do not dominate model training:

\[ f(x) = \begin{cases} \left( \frac{x}{x_{\max}} \right)^\alpha & \text{if } x < x_{\max} \\ 1 & \text{otherwise} \end{cases} \]

Standard default hyperparameters are \(x_{\max} = 100\) and \(\alpha = 0.75\).

\(k_1 = \text{"solid"}\) \(1.0 \times 10^{-3}\) \(1.0 \times 10^{-5}\) \(\mathbf{100.0} \gg 1\) Strongly related to ice, unrelated to steam

\(k_3 = \text{"water"}\) \(5.0 \times 10^{-3}\) \(5.0 \times 10^{-3}\) \(\mathbf{1.0} \approx 1\) Related to both (shared baseline property)
\(k_4 = \text{"fashion"}\) \(1.0 \times 10^{-5}\) \(1.0 \times 10^{-5}\) \(\mathbf{1.0} \approx 1\) Unrelated to both (noise baseline)

Key Takeaway: Ratios \(\gg 1\) or \(\ll 1\) select for discriminative properties (solid vs gas), while ratios \(\approx 1\) eliminate shared associations (water) or irrelevant noise (fashion).

4.3.6 Assumptions & Scope

Scope & Assumptions:

  • Static co-occurrence matrix requirement: GloVe requires constructing and storing the entire \(|V| \times |V|\) co-occurrence matrix \(X\) in memory/disk before training begins.
  • Symmetric context assumption: Typically assumes symmetric window co-occurrences (\(X_{ij} = X_{ji}\)), meaning \(\mathbf{w}\) and \(\mathbf{\tilde{w}}\) are structurally symmetric.
  • Logarithm of zero count: \(\log(0) \) is undefined; hence, GloVe evaluates the summation only over non-zero matrix entries (\(X_{ij} > 0\)).

4.3.7 Visual Intuition

GloVe maps co-occurrences into a high-dimensional vector space where differences between vectors represent probability log-ratios.

For target vectors \(\mathbf{w}_{\text{ice}}\) and \(\mathbf{w}_{\text{steam}}\), the difference vector \(\,\(\mathbf{w}_{\text{ice}} - \mathbf{w}_{\text{steam}}) \) has a high positive dot product with probe vector \(\mathbf{\tilde{w}}_{\text{solid}}\), a high negative dot product with \(\mathbf{\tilde{w}}_{\text{gas}}\), and near-zero dot product with \(\mathbf{\tilde{w}}_{\text{water}}\).

4.3.8 Pitfalls

Common Traps:

  1. Unweighted least squares: Training least squares without weighting function \(f(X_{ij}) \) causes stop-word co-occurrences (e.g., the–of) to dominate 99% of the loss variance.
  2. Ignoring non-zero sparse filtering: Attempting to iterate over all \(|V|^2\) entries including zeros causes extreme computational slowdown and numerical instability with \(\log(0) \).

4.3.9 Vector Space Properties, Analogies, and t-SNE Visualization

Because vector differences track log-probability ratios, GloVe vectors possess remarkable linear arithmetic properties:

\[ \mathbf{w}_{\text{king}} - \mathbf{w}_{\text{man}} + \mathbf{w}_{\text{woman}} \approx \mathbf{w}_{\text{queen}} \]

To visualize \(d\)-dimensional embedding spaces (e.g., \(d=300\)) on 2D screens, researchers use t-Distributed Stochastic Neighbor Embedding (t-SNE). t-SNE maps high-dimensional vector distances to low-dimensional spatial proximities, grouping semantically related words into distinct visual clusters.

4.3.10 Libraries, Pre-trained Models, and Implementation

Real-world GloVe models are pre-trained on massive open-source text corpora—such as Wikipedia 2014, Gigaword 5, and Common Crawl (up to 840 billion tokens)—and maintained by the Stanford University GloVe Project.

Developers routinely load pre-trained GloVe vectors into Python using libraries like Gensim:

import gensim.downloader as api
# Load pre-trained 100-dimensional GloVe embeddings
glove_vectors = api.load("glove-wiki-gigaword-100")
result = glove_vectors.most_similar(positive=['woman', 'king'], negative=['man'], topn=1)
print(result) # Output: [('queen', 0.7699)]

Q: How does GloVe combine global and local information into a single vector representation?

A: GloVe captures global information by constructing the co-occurrence matrix \(X\) across the entire corpus. It captures local information by counting co-occurrences within specific local context windows (\(\pm 5\) words). The final trained word vector \(\mathbf{w}_i\) incorporates both through the objective function that fits log co-occurrence frequencies.

Q: Are GloVe vectors computed during model inference or during training?

A: All static word embeddings (SGNS, CBOW, GloVe) are constructed offline during the training phase. At inference time, vector representations are fetched via instant table lookups, eliminating runtime computation overhead.

Recap: GloVe combines global matrix factorization with local vector log-bilinear regression, fitting log co-occurrence counts using weighted least squares.

4.4 Foundations of Language Modeling

4.4.1 Definition and Core Concepts

Intuition: Think of your smartphone's auto-complete keyboard. When you type "See you", it suggests "tomorrow", "soon", or "later". It isn't checking whether your plans are factually true—it is calculating which word most naturally follows based on the probability distribution of language learned from millions of text messages.

A Language Model (LM) is a probabilistic system designed to compute the joint probability \(P(W) \) of a sequence of words \(W = (w_1, w_2, \dots, w_n) \), or to estimate the conditional probability \(P(w_n \mid w_1, w_2, \dots, w_{n-1}) \) of predicting the next word token \(w_n\) given a preceding context history \(\,\(w_1, \dots, w_{n-1}) \).

Language modeling underlies both text scoring and text generation. In text generation (autoregressive sampling), a language model iteratively predicts the most probable next word token, appends it to the context, and repeats the process.

4.4.2 Symbol Registry

  • \(W\) — Word sequence token tuple \(\,\(w_1, w_2, \dots, w_n) \) of length \(n\)
  • \(w_i\) — \(i\)-th word token in the sequence
  • \(P(W) \) — Joint probability score assigned to complete word sequence \(W\) (\(P(W) \in [0, 1]\))
  • \(P(w_i \mid w_1, \dots, w_{i-1}) \) — Conditional probability of word \(w_i\) given prior context history
  • \(\prod_{i=1}^n\) — Product operator over sequence index \(1\) through \(n\)

4.4.3 Mathematical Formulation: The Chain Rule of Probability

Formalization: The fundamental identity of language modeling is the Chain Rule of Probability. For any joint distribution over \(n\) random variables, the joint probability \(P(w_1, w_2, \dots, w_n) \) decomposes exactly into a product of conditional probabilities without making any independence assumptions:

\[ P(w_1, w_2, \dots, w_n) = P(w_1) \cdot P(w_2 \mid w_1) \cdot P(w_3 \mid w_1, w_2) \cdots P(w_n \mid w_1, \dots, w_{n-1}) \]

In general product notation:

\[ P(W) = \prod_{i=1}^n P(w_i \mid w_1, w_2, \dots, w_{i-1}) \]

Verbal translation: The joint probability of a sentence equals the probability of the first word, times the probability of the second word given the first, times the probability of the third word given the first two, continuing up to the \(n\)-th word given all preceding words.

4.4.4 Worked Example: Chain Rule Decomposition

Numerical Walkthrough of Chain Rule Decomposition:

Calculate the exact joint probability decomposition for the 4-word sentence \(W = (\text{"its"}, \text{"water"}, \text{"is"}, \text{"transparent"}) \).

Step 1: Write out the exact chain rule expansion.

\[ P(\text{"its water is transparent"}) = P(\text{"its"}) \times P(\text{"water"} \mid \text{"its"}) \times P(\text{"is"} \mid \text{"its", "water"}) \times P(\text{"transparent"} \mid \text{"its", "water", "is"}) \]

Step 2: Plug in empirical conditional probabilities from corpus estimates.

Suppose corpus statistics yield:

  • \(P(\text{"its"}) = 0.05\)
  • \(P(\text{"water"} \mid \text{"its"}) = 0.01\)
  • \(P(\text{"is"} \mid \text{"its", "water"}) = 0.25\)
  • \(P(\text{"transparent"} \mid \text{"its", "water", "is"}) = 0.04\)

Step 3: Multiply conditional probabilities.

\[ P(W) = 0.05 \times 0.01 \times 0.25 \times 0.04 = 0.0005 \times 0.01 = \mathbf{0.000005} = 5.0 \times 10^{-6} \]

Sense check: The result is a valid scalar probability between 0 and 1.

4.4.5 Assumptions & Scope

Scope & Assumptions:

  • Exact chain rule has no independence assumptions: The chain rule formula is mathematically exact. However, estimating long context histories \(P(w_n \mid w_1, \dots, w_{n-1}) \) directly from counts requires infinite corpus data.
  • Fluency vs Truth: \(P(W) \) measures grammatical/linguistic fluency relative to training text, NOT factual accuracy or truthfulness.

4.4.6 Visual Intuition

Language generation operates as a tree expansion over time. Starting from the start of sentence token, the model branches into candidate next words, each assigned a conditional probability. Multiplying probabilities along a specific branch path yields the total joint path probability \(P(W) \).

4.4.7 Pitfalls

Common Traps:

  1. Confusing joint probability with conditional probability: \(P(W) \) is the probability of the entire sequence, whereas \(P(w_n \mid \text{context}) \) is the probability of the single next token given history.
  2. Assuming high probability implies truth: A grammatically fluent sentence stating a false fact ("The sun revolves around the Earth") receives a high \(P(W) \) if the training corpus contains fluent text.

4.4.8 Applications of Language Modeling

Language models are foundational across major NLP application domains:

  • Speech Recognition (ASR): Disambiguates phonetically identical acoustic sequences (e.g., preferring \(P(\text{"recognize speech"}) > P(\text{"wreck a nice beach"}) \)).
  • Spelling & Grammar Correction: Flags low-probability word transitions and suggests fluent replacements.
  • Machine Translation: Scores target-language sentence hypotheses to ensure natural syntax and phrasing.
  • Predictive Text & Keyboard Autocomplete: Ranks candidate word completions in real-time.

4.4.9 Student Questions and Answers

Q: Why do language models rely on probability distributions rather than strict grammatical rules?

A: Natural language is dynamic, fluid, and filled with creative variations. Rule-based grammars are rigid, fragile, and fail on informal or novel text. Probabilistic modeling allows systems to gracefully handle variations, rank competing interpretations, and generalize from large text corpora.

4.4.10 Recap and Bridge

Recap: The Chain Rule of Probability exacts \(P(W) = \prod_{i=1}^n P(w_i \mid w_1, \dots, w_{i-1}) \), breaking sentence scoring into sequential next-word conditional probabilities.

Exam note: Expect exam questions asking you to write out the chain rule expansion for given sentences and compute sentence probabilities.

4.5 The Markov Assumption and N-Gram Models

4.5.1 The Markov Assumption and Context Truncation

Intuition: Imagine trying to guess the next word in a 50-word paragraph by remembering all 49 preceding words verbatim. You would rarely find an exact match in your memory. The Markov Assumption simplifies this: instead of looking back 49 words, you only look back at the last 1 or 2 words to make your prediction.

Computing true conditional probabilities using the full historical context \(P(w_i \mid w_1, \dots, w_{i-1}) \) becomes computationally intractable and sparse for long sequences because exact long word histories rarely repeat verbatim in text corpora.

To make language modeling practical, we apply the Markov Assumption: we assume the probability of a word token \(w_i\) depends only on the preceding \(N-1\) words rather than the entire historical sequence.

4.5.2 Symbol Registry

  • \(N\) — Order of the N-gram model (\(N=1\) for unigram, \(N=2\) for bigram, \(N=3\) for trigram)
  • \(C(w_1, \dots, w_k) \) — Raw co-occurrence count of word sequence \(\,\(w_1, \dots, w_k) \) in corpus
  • \(P_{\text{MLE}}(w_i \mid w_{i-N+1}, \dots, w_{i-1}) \) — Maximum Likelihood Estimate (MLE) of N-gram probability
  • <s>, </s> — Special sentence boundary tokens (start-of-sentence and end-of-sentence)
  • \(\log_{10} P(W) \) — Log-space joint probability score

4.5.3 N-Gram Definitions and Boundary Tokens

An N-gram is a contiguous sequence of \(N\) words.

  • Unigram (\(N=1\)): Assumes complete independence between words: \[ P(w_1, w_2, \dots, w_n) = \prod_{i=1}^n P(w_i) \]
  • Bigram (\(N=2\)): Assumes dependence only on the immediate preceding word (1st-order Markov): \[ P(w_i \mid w_1, \dots, w_{i-1}) \approx P(w_i \mid w_{i-1}) \]
  • Trigram (\(N=3\)): Assumes dependence on the preceding two words (2nd-order Markov): \[ P(w_i \mid w_1, \dots, w_{i-1}) \approx P(w_i \mid w_{i-2}, w_{i-1}) \]

To correctly model sentence initialization and termination, boundary tokens <s> and </s> are added. For a bigram model, one <s> is prepended and one </s> is appended. For a trigram model, two <s> <s> tokens are prepended.

4.5.4 Maximum Likelihood Estimation (MLE) for N-Grams

Formalization: Probabilities in N-gram models are estimated from raw corpus frequency counts using Maximum Likelihood Estimation (MLE):

For a Bigram model:

\[ P_{\text{MLE}}(w_i \mid w_{i-1}) = \frac{C(w_{i-1}, w_i)}{C(w_{i-1})} \]

For a Trigram model:

\[ P_{\text{MLE}}(w_i \mid w_{i-2}, w_{i-1}) = \frac{C(w_{i-2}, w_{i-1}, w_i)}{C(w_{i-2}, w_{i-1})} \]

Under the 1st-order Markov (Bigram) assumption, the joint probability of sentence \(W\) is:

\[ P(W) = \prod_{i=1}^n P(w_i \mid w_{i-1}) \]

4.5.5 Worked Computation: Sentence Probability and Log-Space Arithmetic

Numerical Walkthrough of Bigram Computation and Log-Space Arithmetic:

Calculate the joint probability of the sentence "<s> I want to eat Chinese food </s>" using a trained Bigram model.

Step 1: Write out the Bigram probability decomposition.

\[ P(W) = P(\text{I} \mid \text{\lt s\gt}) \times P(\text{want} \mid \text{I}) \times P(\text{to} \mid \text{want}) \times P(\text{eat} \mid \text{to}) \times P(\text{Chinese} \mid \text{eat}) \times P(\text{food} \mid \text{Chinese}) \times P(\text{\lt /s\gt} \mid \text{food}) \]

Step 2: Substitute empirical MLE bigram probabilities.

Given corpus probabilities:

  • \(P(\text{I} \mid \text{\lt s\gt}) = 0.25\)
  • \(P(\text{want} \mid \text{I}) = 0.33\)
  • \(P(\text{to} \mid \text{want}) = 0.65\)
  • \(P(\text{eat} \mid \text{to}) = 0.28\)
  • \(P(\text{Chinese} \mid \text{eat}) = 0.02\)
  • \(P(\text{food} \mid \text{Chinese}) = 0.60\)
  • \(P(\text{\lt /s\gt} \mid \text{food}) = 0.40\)

Step 3: Direct multiplication.

\[ P(W) = 0.25 \times 0.33 \times 0.65 \times 0.28 \times 0.02 \times 0.60 \times 0.40 = \mathbf{0.00007207} = 7.207 \times 10^{-5} \]

Step 4: Log-Space Summation (Underflow Prevention).

Multiplying long chains of small probabilities causes arithmetic underflow. We convert to log base 10:

\[ \log_{10} P(W) = \sum_{i=1}^n \log_{10} P(w_i \mid w_{i-1}) \] \[ \begin{aligned} \log_{10} P(W) &= \log_{10}(0.25) + \log_{10}(0.33) + \log_{10}(0.65) + \log_{10}(0.28) + \log_{10}(0.02) + \log_{10}(0.60) + \log_{10}(0.40) \\ &= -0.602 - 0.481 - 0.187 - 0.553 - 1.699 - 0.222 - 0.398 = \mathbf{-4.142} \end{aligned} \]

To recover probability: \(10^{-4.142} \approx \mathbf{0.0000721}\).

4.5.6 Assumptions & Scope

Scope & Assumptions:

  • Markov independence assumption: Assumes \(w_i\) depends strictly on the last \(N-1\) words, completely ignoring long-distance syntactic dependencies.
  • Corpus sensitivity: MLE probabilities are highly sensitive to training corpus topic distribution and domain vocabulary.

4.5.7 Visual Intuition

Bigram models can be visualized as a state transition matrix or directed graph where words represent nodes and edges represent transition probabilities \(P(w_i \mid w_{i-1}) \). A sentence is a path through this graph, and the path probability is the product of edge weights.

4.5.8 Pitfalls

Common Traps:

  1. Numerical underflow: Multiplying raw floating-point probabilities for long sentences underflows to 0.0. Always sum log probabilities.
  2. Missing start/end tokens: Omitting <s> or </s> prevents proper normalization of sentence starts and lengths.

4.5.9 Student Questions and Answers

Q: Why do we use higher-order N-grams like trigrams or 4-grams instead of unigrams?

A: Unigram models treat all words as independent, producing ungrammatical collections of frequent words. Trigrams and 4-grams capture richer local context and syntactic patterns, yielding dramatically higher fluency.

Q: Do we use log base 2 or base 10 for probabilities?

A: Log base 10 is standard for web-scale corpora to prevent extreme values. Log base 2 is common in information theory and perplexity formulas (as described in Jurafsky and Martin - Speech and Language Processing). Both yield identical relative model rankings.

4.5.10 Recap and Bridge

Recap: The Markov assumption truncates context to \(N-1\) words, making MLE N-gram probability counting tractable and log-space addition stable.

Exam note: Expect Bigram sentence probability calculations requiring conversion into log base 10 space.

4.6 The Zero Probability Problem and Laplace (Add-One) Smoothing

4.6.1 Motivation: Why Zero Probabilities Break Language Models

Intuition: Imagine a language model evaluating a sentence written by a human. If the text includes a completely natural word pair that just happened never to appear in the model's training dataset, raw Maximum Likelihood Estimation assigns that single pair a probability of 0. Because sequence probability is a product of terms, a single zero probability turns the entire sentence score to 0—failing the model completely.

If a test sentence contains a single N-gram that never occurred in the training corpus (such as \(C(\text{"eat"}, \text{"Chinese"}) = 0\)), its unsmoothed Maximum Likelihood Estimate (MLE) probability becomes zero:

\[ P_{\text{MLE}}(\text{"Chinese"} \mid \text{"eat"}) = \frac{C(\text{"eat"}, \text{"Chinese"})}{C(\text{"eat"})} = \frac{0}{C(\text{"eat"})} = 0 \]

Because sequence probability is computed by multiplying conditional probabilities under the chain rule, a single zero term causes the overall sentence joint probability to collapse to zero:

\[ P(W) = 0 \]

This zero probability problem makes unsmoothed language models fragile when evaluating novel test text. Smoothing algorithms fix this by shaving a small fraction of probability mass from frequent N-grams and reallocating it to unseen N-grams.

4.6.2 Symbol Registry

  • \(|V|\) — Vocabulary size (total unique words in training corpus)
  • \(C(w_{i-1}, w_i) \) — Raw unsmoothed bigram count
  • \(C(w_{i-1}) \) — Raw unsmoothed unigram context count
  • \(P_{\text{Laplace}}(w_i \mid w_{i-1}) \) — Laplace-smoothed bigram conditional probability
  • \(C^*(w_{i-1}, w_i) \) — Effective adjusted count under Laplace smoothing
  • \(k\) — Fractional smoothing parameter in Add-\(k\) smoothing (\(k \in (0, 1]\))

4.6.3 Mathematical Formulation: Laplace Add-One Smoothing

Formalization: Laplace (Add-One) smoothing adds \(1\) to every possible N-gram count in the numerator. To ensure that probabilities across all \(|V|\) candidate next words still sum to \(1.0\), the denominator is augmented by \(|V|\):

For a Bigram model:

\[ P_{\text{Laplace}}(w_i \mid w_{i-1}) = \frac{C(w_{i-1}, w_i) + 1}{C(w_{i-1}) + |V|} \]

The effective adjusted count \(C^*\) (the count that would yield this exact probability without denominator alteration) is:

\[ C^*(w_{i-1}, w_i) = \frac{(C(w_{i-1}, w_i) + 1) \times C(w_{i-1})}{C(w_{i-1}) + |V|} \]

4.6.4 Worked Computation: Updated Bigram Probabilities

Numerical Walkthrough of Laplace Add-One Smoothing:

Consider a corpus with vocabulary size \(|V| = 9222\) unique words.

Context word \(w_{i-1} = \text{"want"}\) has unigram count \(C(\text{"want"}) = 2533\).

Raw bigram counts following "want":

  1. \(C(\text{"want"}, \text{"to"}) = 827\)
  2. \(C(\text{"want"}, \text{"eat"}) = 5\)
  3. \(C(\text{"want"}, \text{"Chinese"}) = 0\) (unseen bigram)

Step 1: Compute Unsmoothed MLE Probabilities.

  • \(P_{\text{MLE}}(\text{"to"} \mid \text{"want"}) = \frac{827}{2533} \approx \mathbf{0.3264}\)
  • \(P_{\text{MLE}}(\text{"eat"} \mid \text{"want"}) = \frac{5}{2533} \approx \mathbf{0.00197}\)
  • \(P_{\text{MLE}}(\text{"Chinese"} \mid \text{"want"}) = \frac{0}{2533} = \mathbf{0.0}\)

Step 2: Compute Laplace-Smoothed Probabilities (\(|V| = 9222\)).

Augmented Denominator \(= C(\text{"want"}) + |V| = 2533 + 9222 = \mathbf{11755}\).

  • \(P_{\text{Laplace}}(\text{"to"} \mid \text{"want"}) = \frac{827 + 1}{11755} = \frac{828}{11755} \approx \mathbf{0.07044}\)
  • \(P_{\text{Laplace}}(\text{"eat"} \mid \text{"want"}) = \frac{5 + 1}{11755} = \frac{6}{11755} \approx \mathbf{0.000510}\)
  • \(P_{\text{Laplace}}(\text{"Chinese"} \mid \text{"want"}) = \frac{0 + 1}{11755} = \frac{1}{11755} \approx \mathbf{0.00008507}\)

Step 3: Compute Effective Adjusted Counts (\(C^*\)).

  • \(C^*(\text{"want"}, \text{"to"}) = \frac{828 \times 2533}{11755} \approx \mathbf{178.4}\) (dropped severely from 827)
  • \(C^*(\text{"want"}, \text{"Chinese"}) = \frac{1 \times 2533}{11755} \approx \mathbf{0.215}\) (increased from 0)

Sense check: Probabilities sum to 1, zero probability is eliminated, but frequent bigram count dropped heavily.

4.6.5 Assumptions & Scope

Scope & Assumptions:

  • Uniform prior assumption: Laplace smoothing implicitly assumes a uniform prior over all unseen N-grams, treating every unseen bigram as equally probable (\(+1\)).
  • Severe count distortion: In large-vocabulary settings (\(|V| \ge 100,000\)), adding \(|V|\) to the denominator shifts excessive probability mass to zeros, distorting empirical counts.

4.6.6 Visual Intuition

Imagine probability mass as water in buckets. Unsmoothed MLE leaves empty buckets (\(0.0\)) for unseen N-grams. Laplace smoothing scoops water out of high-count buckets (like ("want", "to")) and pours equal \(+1\) drops into every empty bucket across the entire vocabulary.

4.6.7 Pitfalls

Common Traps:

  1. Forgetting \(|V|\) in the denominator: Adding \(+1\) to every numerator without adding \(+|V|\) to the denominator causes probabilities to sum to \(> 1.0\).
  2. Using raw \(V\) vs vocabulary size: \(|V|\) must equal the total count of unique words in the vocabulary, not the total word token count of the corpus.

4.6.8 Student Questions and Answers

Q: Why do we add \(|V|\) to the denominator in Laplace smoothing?

A: Since we add \(1\) to the count of every possible vocabulary word in the numerator, and there are \(|V|\) possible vocabulary words, the total numerator sum increases by \(|V| \times 1 = |V|\). Adding \(|V|\) to the denominator ensures that conditional probabilities across all candidate next words sum to exactly \(1.0\).

Q: Can we add a smaller constant like \(0.5\) or \(0.1\) instead of \(1\)?

A: Yes, this variation is called Add-\(k\) smoothing (or Lidstone smoothing), where a fractional constant \(k \in (0, 1) \) is added:

\[ P_{\text{Add-}k}(w_i \mid w_{i-1}) = \frac{C(w_{i-1}, w_i) + k}{C(w_{i-1}) + k|V|} \]

However, Add-\(k\) still distorts count statistics significantly.

4.6.9 Recap and Bridge

Recap: Laplace smoothing eliminates zero probabilities by adding \(+1\) to numerators and \(+|V|\) to denominators, but heavily distorts frequent N-gram counts.

Exam note: Expect numerical problems calculating Laplace-smoothed probabilities and effective counts \(C^*\) given \(C(w_{i-1}, w_i) \), \(C(w_{i-1}) \), and \(|V|\).

4.7 Advanced Smoothing: Interpolation and Backoff

4.7.1 Linear Interpolation

Intuition: Imagine a detective solving a case. Instead of relying solely on the single most specific clue (trigram), or ignoring specific clues in favor of general intuition (unigram), linear interpolation blends information from all clue levels simultaneously—giving the highest weight to specific evidence, but falling back gracefully on general patterns when specific clues are missing.

Rather than relying exclusively on a single N-gram order, Linear Interpolation combines probability estimates from higher-order and lower-order N-grams simultaneously. If a trigram count is zero or sparse, its corresponding bigram and unigram probabilities still contribute positive probability mass to the estimate.

Linear interpolation calculates the smoothed trigram probability as a weighted linear combination of Trigram, Bigram, and Unigram Maximum Likelihood Estimates:

\[ P_{\text{Interpolated}}(w_i \mid w_{i-2}, w_{i-1}) = \lambda_3 P_{\text{MLE}}(w_i \mid w_{i-2}, w_{i-1}) + \lambda_2 P_{\text{MLE}}(w_i \mid w_{i-1}) + \lambda_1 P_{\text{MLE}}(w_i) \]

To guarantee that \(P_{\text{Interpolated}}\) forms a valid probability distribution summing to \(1.0\), the interpolation weights must satisfy:

\[ \sum_{k=1}^3 \lambda_k = 1 \quad \text{and} \quad \lambda_k \ge 0 \]

In context-conditional interpolation, the weights \(\lambda_k(w_{i-2}^{i-1}) \) are made functions of context frequency to give higher weight to higher-order N-grams when context counts are abundant.

4.7.2 Symbol Registry

  • \(\lambda_1, \lambda_2, \lambda_3\) — Interpolation weights for unigram, bigram, and trigram (\(\sum \lambda_k = 1\))
  • \(S(w_i \mid w_{i-k+1}^{i-1}) \) — Stupid Backoff score for word \(w_i\) given preceding context
  • \(\alpha\) — Backoff penalty factor (typically \(\alpha = 0.4\))
  • \(N_{\text{total}}\) — Total token count in corpus

4.7.3 Stupid Backoff

Formalization: In Stupid Backoff (introduced by Brants et al. at Google), higher-order N-grams are prioritized. If a higher-order N-gram count is non-zero (\(C > 0\)), the model uses its raw un-normalized MLE probability directly. If the count is zero (\(C = 0\)), the model "backs off" to the lower-order N-gram, penalizing the lower-order score by a constant factor \(\alpha = 0.4\).

The recursive formulation is:

\[ S(w_i \mid w_{i-k+1}^{i-1}) = \begin{cases} \frac{C(w_{i-k+1}^i)}{C(w_{i-k+1}^{i-1})} & \text{if } C(w_{i-k+1}^i) > 0 \\ \alpha \cdot S(w_i \mid w_{i-k+2}^{i-1}) & \text{otherwise} \end{cases} \]

Recursion terminates at the unigram base case:

\[ S(w_i) = \frac{C(w_i)}{N_{\text{total}}} \]

4.7.4 Worked Example: Stupid Backoff Computation

Numerical Walkthrough of Stupid Backoff:

Consider evaluating \(S(\text{"food"} \mid \text{"eat"}, \text{"Chinese"}) \) with backoff penalty \(\alpha = 0.4\).

Corpus counts:

  • \(C(\text{"eat"}, \text{"Chinese"}, \text{"food"}) = 0\) (unseen trigram)
  • \(C(\text{"Chinese"}, \text{"food"}) = 600\)
  • \(C(\text{"Chinese"}) = 1000\)

Step 1: Check Trigram count \(C(\text{"eat"}, \text{"Chinese"}, \text{"food"}) \).

Count is \(0\), so back off to Bigram score penalized by \(\alpha = 0.4\):

\[ S(\text{"food"} \mid \text{"eat"}, \text{"Chinese"}) = 0.4 \times S(\text{"food"} \mid \text{"Chinese"}) \]

Step 2: Evaluate Bigram score \(S(\text{"food"} \mid \text{"Chinese"}) \).

\(C(\text{"Chinese"}, \text{"food"}) = 600 > 0\).

\[ S(\text{"food"} \mid \text{"Chinese"}) = \frac{C(\text{"Chinese"}, \text{"food"})}{C(\text{"Chinese"})} = \frac{600}{1000} = \mathbf{0.60} \]

Step 3: Compute final Stupid Backoff score.

\[ S(\text{"food"} \mid \text{"eat"}, \text{"Chinese"}) = 0.4 \times 0.60 = \mathbf{0.24} \]

Sense check: Trigram missing \(\rightarrow\) backed off to bigram (\(0.60\)) and scaled by \(\alpha = 0.4\), yielding \(0.24\).

4.7.5 Assumptions & Scope

Scope & Assumptions:

  • Non-probabilistic output of Stupid Backoff: Stupid Backoff scores do NOT sum to \(1.0\) across the vocabulary. It produces relative scores, not proper probability distributions.
  • Interpolation weight constraint: Linear interpolation requires tuning weights \(\lambda_k\) on a held-out validation dataset via EM or grid search.

4.7.6 Visual Intuition

Interpolation behaves like a multi-channel audio mixer, combining unigram, bigram, and trigram channels with slider knobs \(\lambda_1, \lambda_2, \lambda_3\). Backoff behaves like a fallback waterfall switch: try channel 3; if silent (\(0\)), flip switch to channel 2 and attenuate by \(0.4\).

4.7.7 Pitfalls

Common Traps:

  1. Unconstrained interpolation weights: Allowing \(\lambda_1 + \lambda_2 + \lambda_3 \neq 1\) breaks the probability distribution contract.
  2. Treating Stupid Backoff as probabilities: Using Stupid Backoff scores in places requiring strict probability distributions (like perplexity calculations) leads to invalid metrics.

4.7.8 Comparative Analysis: Interpolation vs. Backoff

Feature Linear Interpolation Backoff (Stupid Backoff)
:--- :--- :---
Strategy Blends all N-gram orders (trigram, bigram, unigram) together Uses highest available N-gram order; backs off on zero count
Hyperparameters Requires weights \(\sum \lambda_k = 1\) Uses constant backoff multiplier \(\alpha = 0.4\)
Normalization Produces valid, normalized probability distributions Scores do not sum to 1; suitable for ranking and completion
Computation Evaluates all N-gram levels for every token Evaluates lower levels only when higher levels are missing

4.7.9 Student Questions and Answers

Q: Do interpolation weights \(\lambda_1, \lambda_2, \lambda_3\) have to sum to 1?

A: Yes, the constraint \(\lambda_1 + \lambda_2 + \lambda_3 = 1\) is strictly required for linear interpolation so that the resulting mixture is a valid probability distribution.

Q: Why is it called "Stupid Backoff"?

A: The creators named it "Stupid Backoff" because it lacks complex mathematical normalization, relying instead on a simple constant multiplier \(\alpha = 0.4\). Despite its simplicity, it achieves state-of-the-art performance on massive web-scale text corpora.

4.7.10 Recap and Bridge

Recap: Linear interpolation blends N-gram orders using normalized weights \(\sum \lambda_k = 1\), while Stupid Backoff prioritizes high-order N-grams and backs off with penalty \(\alpha = 0.4\).

4.8 Transition to Neural Language Models

4.8.1 From N-Grams to Neural Architecture

Intuition: Imagine trying to learn a language by memorizing a giant paper lookup dictionary of exact 3-word combinations. If you see "the green automobile", but your dictionary only lists "the green car", you get stuck. Neural language models fix this by understanding that "car" and "automobile" point to similar concepts in a continuous vector space, allowing them to generalize to novel phrases effortlessly.

Statistical N-gram language models suffer from two primary structural limitations:

  1. Sparsity & Lack of Generalization: N-gram models treat words as atomic discrete tokens. They cannot generalize across semantically related words. Knowing \(C(\text{"the"}, \text{"green"}, \text{"car"}) \) provides zero probability mass for \(C(\text{"the"}, \text{"green"}, \text{"automobile"}) \).
  2. Exponential Parameter Explosion: The number of parameters in an N-gram count table grows exponentially as \(|V|^N\). Consequently, classical N-gram models are forced to limit context windows to small sizes (\(N \le 5\)).

Neural language models solve both limitations by projecting discrete word tokens into continuous dense vector spaces (embeddings) and passing those representations through neural network layers (Feedforward Networks, RNNs, LSTMs, Transformers).

4.8.2 Symbol Registry

  • \(|V|\) — Vocabulary size
  • \(N\) — Context window length
  • \(\text{PPL}\) — Perplexity metric evaluating model surprise (\(\text{PPL} = P(W)^{-1/n}\))

4.8.3 Looking Ahead: Perplexity and Model Evaluation

Formalization: To evaluate language models intrinsically without executing expensive downstream tasks (like translation or ASR), NLP uses Perplexity (PPL).

Perplexity measures the effective branching factor of a language model—intuitively, the number of equally likely words the model must choose from at each step. Mathematically, perplexity is the exponentiated cross-entropy loss over test text:

\[ \text{PPL}(W) = P(w_1, w_2, \dots, w_n)^{-\frac{1}{n}} = \exp\left( -\frac{1}{n} \sum_{i=1}^n \log P(w_i \mid w_{i-1}) \right) \]

Lower perplexity indicates higher predictive certainty and superior model fluency.

4.8.4 Student Questions and Answers

Q: Are N-gram counts pre-computed or generated on the fly during user queries?

A: All N-gram count tables and co-occurrence statistics are compiled offline during training. At runtime, system queries perform instant key-value table lookups to fetch probabilities without incurring real-time search overhead.

4.8.5 Recap and Bridge

Recap: Statistical N-grams are limited by sparsity and exponential parameter growth; neural language models replace discrete counts with continuous vector projections and neural layers.

Exam note: Note the transition from N-gram count tables to neural embeddings and intrinsic evaluation using Perplexity.

Must-know: SGNS replaces multi-class Softmax over V with binary logistic regression over 1 positive context word and K negative samples.

\[\mathbf{v}_w^{(\text{new})} = \mathbf{v}_w^{(\text{old})} - \eta \cdot \left[ (\sigma(\mathbf{v}_w^\top \mathbf{u}_{c^+}) - 1)\mathbf{u}_{c^+} + \sum_{k=1}^K \sigma(\mathbf{v}_w^\top \mathbf{u}_{c^-_k})\mathbf{u}_{c^-_k} \right]\]

⚠️ Top pitfall: Using un-smoothed unigram noise sampling instead of raising unigram frequencies to 3/4 power.

Continuous Bag of Words (CBOW)

Must-know: CBOW predicts a center target word from an averaged bag of surrounding context word vectors using Softmax.

\[P(w_j \mid c_1, \dots, c_C) = \frac{\exp(\mathbf{v}_{w_j}^\top \mathbf{\bar{u}})}{\sum_{k=1}^{|V|} \exp(\mathbf{v}_{w_k}^\top \mathbf{\bar{u}})}\]

⚠️ Top pitfall: Confusing Sigmoid (binary classification) with Softmax (multi-class probability distribution).

Self-check: Which model is better suited for rare words: CBOW or Skip-Gram?

Global Vectors for Word Representation (GloVe)

Must-know: GloVe combines global co-occurrence matrix counts with local log-bilinear vector dot products using weighted least squares loss.

\[\mathcal{J} = \sum_{i=1}^{|V|} \sum_{j=1}^{|V|} f(X_{ij}) \left( \mathbf{w}_i^\top \mathbf{\tilde{w}}_j + b_i + \tilde{b}_j - \log X_{ij} \right)^2\]

⚠️ Top pitfall: Confusing raw co-occurrence probability P_{ij} with the discriminative probability ratio P_{ik}/P_{jk}.

Foundations of Language Modeling

Must-know: The Chain Rule decomposes joint sentence probability into a exact product of sequential conditional probabilities P(W) = \prod_{i=1}^n P(w_i \mid w_1, \dots, w_{i-1}).

\[P(W) = \prod_{i=1}^n P(w_i \mid w_1, \dots, w_{i-1})\]

The Markov Assumption and N-Gram Models

Must-know: Bigram MLE probability is P(w_i \mid w_{i-1}) = \frac{C(w_{i-1}, w_i)}{C(w_{i-1})}, and sentence probabilities must be computed in log space to prevent numerical underflow.

\[\log_{10} P(W) = \sum_{i=1}^n \log_{10} P(w_i \mid w_{i-1})\]

⚠️ Top pitfall: Multiplying raw floating-point probabilities directly for long sentences causing underflow to 0.0.

Self-check: Why is the Markov assumption necessary for N-gram language models?

Connects to: 4.4, 4.6

The Zero Probability Problem and Laplace Smoothing

Must-know: Laplace smoothing formula is P_{\text{Laplace}}(w_i \mid w_{i-1}) = \frac{C(w_{i-1}, w_i) + 1}{C(w_{i-1}) + |V|}, adding |V| to denominator to preserve sum to 1.

\[P_{\text{Laplace}}(w_i \mid w_{i-1}) = \frac{C(w_{i-1}, w_i) + 1}{C(w_{i-1}) + |V|}\]

⚠️ Top pitfall: Adding +1 to numerator without adding +|V| to denominator.

Advanced Smoothing: Interpolation and Backoff

Must-know: Linear interpolation requires \sum \lambda_k = 1. Stupid Backoff uses constant multiplier \alpha = 0.4 on zero counts and does not produce normalized probabilities.
