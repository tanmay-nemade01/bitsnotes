4. Common Mistakes

  • Confusing CBOW and Skip-Gram. CBOW predicts the center from context; Skip-Gram predicts context from the center.
  • Perplexity on different vocabularies. You can only compare perplexity between models with the same tokenisation and vocab.
  • Treating embeddings as directly comparable across models. Vectors from different algorithms live in different spaces.
  • Viterbi without log-probs. Multiplying many small probabilities underflows; work in log space.
  • Assuming LLMs are truthful. Prompt engineering shapes behaviour; it does not guarantee factual output.

5. Worked Example — POS tagging

Tag “The dog barks” with tags {DET, NOUN, VERB}. Emission: P(NOUN|dog)=0.9. Transition: P(NOUN|DET)=0.8, P(VERB|NOUN)=0.7.

Step 1 — “The”
Force DET (determiner). Viterbi score for DET = 0 (log 1).
Step 2 — “dog”
Best tag = argmax over prev: DET→NOUN = 0 + log 0.8 + log 0.9 ≈ −0.21. Choose NOUN.
Step 3 — “barks”
NOUN→VERB = −0.21 + log 0.7 ≈ −0.57. Choose VERB. Decoded sequence: DET · NOUN · VERB.
Takeaway: Viterbi prunes the combinatorial tag space to N²T using dynamic programming with greedy pruning at each step.
