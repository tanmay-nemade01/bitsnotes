4. Common Mistakes

  • DFS on a shallow-wide tree. DFS blows up in depth before finding a near-root solution; prefer BFS or IDS.
  • Greedy search incompleteness. Greedy can cycle and never reach the goal; it is not complete.
  • Non-admissible heuristic. A* loses optimality the moment h(n) overestimates cost-to-goal.
  • Confusing UCS and Dijkstra. On a weighted graph with no heuristic, UCS is exactly Dijkstra's algorithm.
  • Alpha-beta without optimal ordering. Pruning only reaches its O(bd/2) best case with good move ordering.

5. Worked Example — route finding

Find the cheapest path A→G. Edges: A→B (1), A→C (4), B→G (6), C→G (2). Heuristic h(G)=0, h(B)=5, h(C)=1.

UCS (no heuristic)
Expand A (g=0) → B(g=1), C(g=4). Pop B → G(g=7). Path A→B→G cost 7.
A* (f = g + h)
A: f=0. B: f=1+5=6, C: f=4+1=5 → pop C first → G: f=6+0=6. Path A→C→G cost 6 — optimal, found with fewer expansions.
Takeaway: the admissible heuristic let A* skip the suboptimal B branch and find the cheaper A→C→G route.
